# Features of Node.js

In the last lesson, we saw how Node.js grew from a small server experiment into a popular JavaScript runtime. What makes Node.js useful for building modern applications?
The answer is its runtime features. Let us look at them one by one.

## 1. Runs JavaScript Outside the Browser

Node.js uses Google's **V8 engine** to execute JavaScript from the terminal, a server, or another environment without opening a browser.

```js
console.log("Hello from Node.js!");
Run the file with `node app.js` and Node.js prints the message to the terminal.

## 2. Event-Driven and Non-Blocking

This non-blocking design is useful for applications that handle many network requests at the same time. The application does not need to stop everything whenever one request is waiting for input or output.

## 3. Asynchronous APIs

Node.js provides asynchronous versions of many operations. For example, `fs.readFile` reads a file and calls a function when the operation is complete:

```js
const fs = require("node:fs");

fs.readFile("message.txt", "utf8", (error, data) => {
  if (error) {
    console.error(error.message);
    return;
  }

  console.log(data);
});

console.log("The program can do other work while the file is read.");
```

## 4. Built-In Modules

Node.js includes useful modules without requiring an extra package. Some common examples are:

- `node:fs` for files and directories
- `node:http` for HTTP servers and requests
- `node:path` for working with file paths
- `node:os` for operating-system information
- `node:events` for creating and handling events

These modules give Node.js access to capabilities that browser JavaScript does not normally have.

## 5. Simple HTTP Servers

The built-in `http` module can create a web server with only a few lines of code:

```js
const http = require("node:http");

const server = http.createServer((request, response) => {
  response.end("Hello from the Node.js server!");
});

server.listen(3000, () => {
  console.log("Server running at http://localhost:3000");
});
```

Node.js can receive requests, run application logic, communicate with a database, and send responses back to clients.

## 6. Streams and Buffers

Node.js can process data as it arrives instead of loading everything into memory at once. This is useful for large files, video, uploads, and network connections.

- **Streams** process data piece by piece.
- **Buffers** represent raw binary data.

Processing data in smaller pieces can reduce memory usage and allow an application to start responding sooner.

## 7. Modules and Code Organization

Node.js applications can split code into reusable modules. A module can export a function, object, or class, and another file can import it when needed.

This keeps large applications organized and makes individual parts easier to test and maintain. Node.js supports both CommonJS modules and modern ECMAScript modules.

## 8. `process` and Command-Line Access

The global `process` object gives a Node.js program information about its environment and control over its execution:

```js
console.log("Node version:", process.version);
console.log("Arguments:", process.argv.slice(2));
```

This makes Node.js useful for command-line tools, scripts, automation, and applications configured with environment variables.

## 9. npm and a Large Ecosystem

Node.js includes access to **npm**, the Node Package Manager. npm lets developers install packages for web frameworks, database clients, testing, validation, logging, and many other tasks.

Packages are listed in `package.json`, so other developers can install the same dependencies and run the project consistently.

## 10. Cross-Platform Development

Node.js runs on macOS, Windows, and Linux. A Node.js application can usually be developed on one operating system and deployed to another with little or no code change.

This makes Node.js a practical choice for local tools, cloud services, containers, and production servers.

## Key Takeaways

- Node.js runs JavaScript outside the browser using the V8 engine.
- Its event loop and non-blocking APIs are designed for I/O-heavy applications.
- Built-in modules provide access to files, networks, paths, processes, and events.
- HTTP servers, streams, and buffers support web and data-processing applications.
- Modules help organize code, while `process` connects programs to the operating system.
- npm and a large ecosystem make Node.js easy to extend.
- Node.js runs across macOS, Windows, and Linux.
