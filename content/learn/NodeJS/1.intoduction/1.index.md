# What is Node.js?

> **Node.js is a JavaScript runtime that lets you run JavaScript outside a web browser.**

JavaScript was first created for web browsers. Node.js makes it possible to use the same language on a server, in command-line tools, and in scripts that automate everyday tasks.

## A Movie Ticket Application: Where Node.js Fits

Anita owns a cinema hall and wants customers to book tickets online. The browser can show the available seats and collect the customer's choices, but it should not connect directly to the cinema's database.

Node.js can run on the server and act as the secure middle layer. It can:

- Receive booking requests from the browser
- Check whether seats are available
- Save bookings in a database
- Return a response to the customer

The browser handles the interface, while Node.js handles the server-side work.

## How Node.js Runs JavaScript

Node.js uses the **V8 JavaScript engine**, the same engine used by Google Chrome, to execute JavaScript code. Node.js adds features that browsers do not normally provide, including:

- **File system access** for reading and writing files
- **Networking APIs** for creating servers and communicating over the internet
- **Process information** for reading command-line arguments and environment variables
- **Module support** for organizing code into reusable files

Node.js is not a new programming language. It is an environment that provides JavaScript with tools for server-side and system-level programming.

## Your First Node.js Program

Create a file named `app.js`:

```js
const message = "Hello from Node.js!";

console.log(message);
```

Run it from your terminal with:

```bash
node app.js
```

The output is:

```text
Hello from Node.js!
```

The `node` command starts the Node.js runtime, loads `app.js`, executes the JavaScript, and prints the result to the terminal.

## Node.js in One Sentence

Node.js is a runtime built on V8 that allows JavaScript to run outside the browser, especially for servers, tools, scripts, and applications that communicate over a network.

## Key Takeaways

- Node.js runs JavaScript outside the browser.
- It uses the V8 engine to execute JavaScript.
- It provides APIs for files, networking, processes, and modules.
- Its non-blocking, event-driven design is useful for I/O-heavy applications.
- npm helps developers install and manage reusable packages.
- The `node` command runs a JavaScript file from the terminal.
