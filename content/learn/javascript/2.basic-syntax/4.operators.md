# Operators

Think about a calculator. You enter numbers, press `+`, `-`, or `×`, and get an answer. Those buttons are **operators**.

In JavaScript, an **operator is a symbol that performs an action on values**. The values it works on are called **operands**.

```js
let total = 10 + 5;
//          ↑  ↑  ↑
//   operand  operator  operand
```

Let us explore the different kinds of operators one by one.

---

## 1. Arithmetic Operators

These are used for **maths**.

| Operator | Meaning | Example | Result |
|----------|---------|---------|--------|
| `+` | Addition | `10 + 3` | `13` |
| `-` | Subtraction | `10 - 3` | `7` |
| `*` | Multiplication | `10 * 3` | `30` |
| `/` | Division | `10 / 3` | `3.3333...` |
| `%` | Remainder (modulus) | `10 % 3` | `1` |
| `**` | Power (exponent) | `2 ** 3` | `8` |

**Real example: calculating a restaurant bill**

```js
let pizza = 350;
let coldDrink = 60;
let people = 2;

let total = pizza + coldDrink;       // 410
let perPerson = total / people;      // 205

console.log("Each person pays ₹" + perPerson);
```

**Key points:**
- `%` gives the **remainder** after division. For example, `10 % 3` means 10 ÷ 3 = 3, with **1 left over**.
- `%` is very useful to check **even or odd** numbers:

```js
console.log(8 % 2);   // 0 → even
console.log(7 % 2);   // 1 → odd
```

- Dividing by zero gives `Infinity`, not an error:

```js
console.log(10 / 0);   // Infinity
```

---

## 2. Integer Division

In some languages, `10 / 3` gives `3` (only the whole number). **JavaScript does not do this.** It always gives the full decimal answer.

```js
console.log(10 / 3);   // 3.3333333333333335
```

So how do we get only the **whole number part**? We use the `Math` methods:

| Method | What it does | `10 / 3` | `-10 / 3` |
|--------|-------------|----------|-----------|
| `Math.trunc()` | Removes the decimal part | `3` | `-3` |
| `Math.floor()` | Rounds **down** | `3` | `-4` |

```js
console.log(Math.trunc(10 / 3));   // 3
console.log(Math.floor(10 / 3));   // 3
```

**Real example: packing laddoos into boxes**

```js
let laddoos = 25;
let perBox = 6;

let fullBoxes = Math.trunc(laddoos / perBox);   // 4
let leftOver  = laddoos % perBox;               // 1

console.log(fullBoxes + " boxes, " + leftOver + " laddoo left");
// 4 boxes, 1 laddoo left
```

> **Tip:** For positive numbers, both methods give the same answer. For negative numbers, use `Math.trunc()` if you only want to remove the decimals.

## 3. Modulus with Negative Numbers

The `%` operator follows one simple rule:

> **The answer takes the sign of the first number** (the number on the left).

```js
console.log( 10 %  3);   //  1
console.log(-10 %  3);   // -1  ← left number is negative
console.log( 10 % -3);   //  1  ← left number is positive
console.log(-10 % -3);   // -1
```

**Key points:**
- Only the **left side** decides whether the answer is positive or negative.
- This is why `-7 % 2` gives `-1`, not `1`. Keep this in mind when checking odd numbers:

```js
let num = -7;

console.log(num % 2 === 1);    // false ❌ (because the result is -1)
console.log(num % 2 !== 0);    // true  ✅ safer way to check odd numbers
```

## 4. String Concatenation with `+`

The `+` operator has **two jobs**:

- With numbers, it **adds**.
- With strings, it **joins** (this is called concatenation).

```js
let firstName = "Rahul";
let lastName = "Sharma";

console.log(firstName + " " + lastName);   // Rahul Sharma
```

**If even one side is a string, `+` joins instead of adding:**

```js
console.log(5 + 5);       // 10
console.log("5" + 5);     // "55"
console.log(5 + "5");     // "55"
```

**JavaScript reads from left to right, so order matters:**

```js
console.log(2 + 3 + "px");   // "5px"  → first 2 + 3 = 5, then "5px"
console.log("px" + 2 + 3);   // "px23" → a string comes first, so everything is joined
```

**A cleaner way: template literals**

Instead of using many `+` signs, use backticks and `${ }`:

```js
let item = "Chai";
let price = 20;

console.log(`${item} costs ₹${price}`);   // Chai costs ₹20
```

## 5. Unary Operators

A **unary** operator works on **only one value**.

| Operator | Meaning | Example | Result |
|----------|---------|---------|--------|
| `+` | Converts to a number | `+"42"` | `42` |
| `-` | Makes negative / converts | `-"5"` | `-5` |
| `++` | Increases by 1 | `x++` | `x + 1` |
| `--` | Decreases by 1 | `x--` | `x - 1` |
| `!` | Reverses true/false | `!true` | `false` |
| `typeof` | Gives the type | `typeof 5` | `"number"` |

### Unary `+`: a quick way to convert text into a number

```js
let input = "100";
console.log(+input + 50);   // 150
```

### Increment `++` and Decrement `--`

These add or subtract **1**. But the **position** of `++` changes the result.

**Prefix (`++x`):** increase **first**, then use the value.
**Postfix (`x++`):** use the value **first**, then increase.

```js
let a = 5;
console.log(++a);   // 6 → increased first, then printed
console.log(a);     // 6

let b = 5;
console.log(b++);   // 5 → printed first, then increased
console.log(b);     // 6
```

Think of it like a queue at a ticket counter:
- **Prefix:** You get your token number updated **before** you are called.
- **Postfix:** You are called with your **old** token, and the number updates after.

## 6. Relational (Comparison) Operators

These **compare** two values and always return `true` or `false`.

| Operator | Meaning | Example | Result |
|----------|---------|---------|--------|
| `>` | Greater than | `10 > 5` | `true` |
| `<` | Less than | `10 < 5` | `false` |
| `>=` | Greater than or equal | `18 >= 18` | `true` |
| `<=` | Less than or equal | `15 <= 10` | `false` |
| `===` | Equal (value **and** type) | `5 === 5` | `true` |
| `!==` | Not equal (value **or** type) | `5 !== "5"` | `true` |
| `==` | Equal (converts type first) | `5 == "5"` | `true` |
| `!=` | Not equal (converts type first) | `5 != "5"` | `false` |

**Real example: voting eligibility**

```js
let age = 19;
console.log(age >= 18);   // true → can vote
```

**Key points:**
- Always prefer `===` and `!==`. They do **not** convert types, so there are no surprises.
- When you compare **strings**, JavaScript checks them letter by letter, like a dictionary:

```js
console.log("apple" < "banana");   // true
console.log("10" < "9");           // true 😮 (compares "1" with "9" as text)
```

## 7. Logical Operators

These are used to **combine conditions**.

| Operator | Name | Meaning |
|----------|------|---------|
| `&&` | AND | `true` only if **both** sides are true |
| `\|\|` | OR | `true` if **at least one** side is true |
| `!` | NOT | Reverses the value |
| `??` | Nullish coalescing | Gives a default value for `null` or `undefined` |

### AND `&&`

```js
let hasTicket = true;
let hasID = true;

console.log(hasTicket && hasID);   // true → can enter the stadium
```

### OR `||`

```js
let paidByUPI = false;
let paidByCash = true;

console.log(paidByUPI || paidByCash);   // true → payment done
```

### NOT `!`

```js
let isRaining = false;
console.log(!isRaining);   // true → go outside
```

### Short-Circuiting: JavaScript Stops Early

Logical operators are smart. They **stop checking** as soon as the answer is clear.

- `&&` stops at the **first false** value.
- `||` stops at the **first true** value.

```js
console.log(false && anything);   // false, never checks "anything"
console.log(true || anything);    // true, never checks "anything"
```

They also **return the actual value**, not just `true` or `false`. This is used to set **default values**:

```js
let userName = "";
let displayName = userName || "Guest";

console.log(displayName);   // "Guest"
```

### `??`: a safer way to set defaults

`||` treats `0` and `""` as empty. But sometimes `0` is a **real value**!

```js
let quantity = 0;

console.log(quantity || 1);   // 1 ❌ (0 was a real value!)
console.log(quantity ?? 1);   // 0 ✅ (?? only replaces null or undefined)
```

## 8. Bitwise and Non-Short-Circuit Operators

Computers store numbers as **bits**, which are 0s and 1s. Bitwise operators work directly on these bits.

For example, `5` in binary is `101` and `3` is `011`.

| Operator | Name | Example | Result |
|----------|------|---------|--------|
| `&` | AND | `5 & 3` | `1` |
| `\|` | OR | `5 \| 3` | `7` |
| `^` | XOR | `5 ^ 3` | `6` |
| `~` | NOT | `~5` | `-6` |
| `<<` | Left shift | `5 << 1` | `10` |
| `>>` | Right shift | `5 >> 1` | `2` |
| `>>>` | Unsigned right shift | `-5 >>> 28` | `15` |

**How `5 & 3` works, bit by bit:**

```
  101   (5)
& 011   (3)
-----
  001   (1)   → a bit is 1 only if both bits are 1
```

**A simple use: checking even or odd**

```js
console.log(7 & 1);   // 1 → odd
console.log(8 & 1);   // 0 → even
```

**Shifting is a fast way to multiply or divide by 2:**

```js
console.log(5 << 1);   // 10 (5 × 2)
console.log(20 >> 1);  // 10 (20 ÷ 2)
```

### Non-Short-Circuit Behaviour

`&&` and `||` stop early. But `&` and `|` **always check both sides**, even when the answer is already clear.

```js
function check(name) {
  console.log("Checking " + name);
  return true;
}

false && check("A");   // prints nothing (stopped early)
false &  check("B");   // prints "Checking B" (both sides run)
```

**Key points:**
- `&` and `|` return **numbers** (`0` or `1`), not `true` or `false`.
- For normal conditions, always use `&&` and `||`.
- Bitwise operators are mostly used in **advanced tasks** like graphics, permissions, and performance tricks. As a beginner, just know that they exist.

## 9. Assignment Operators

These **store** a value in a variable.

| Operator | Example | Same as |
|----------|---------|---------|
| `=` | `x = 10` | Store 10 in x |
| `+=` | `x += 5` | `x = x + 5` |
| `-=` | `x -= 5` | `x = x - 5` |
| `*=` | `x *= 2` | `x = x * 2` |
| `/=` | `x /= 2` | `x = x / 2` |
| `%=` | `x %= 3` | `x = x % 3` |
| `**=` | `x **= 2` | `x = x ** 2` |

**Real example: a wallet balance**

```js
let wallet = 1000;

wallet += 500;   // money added    → 1500
wallet -= 200;   // bought a book  → 1300

console.log(wallet);   // 1300
```

**Logical assignment operators** set a value only when needed:

```js
let city;
city ??= "Mumbai";   // set only if city is null or undefined
console.log(city);   // Mumbai

let score = 0;
score ||= 10;        // set if score is falsy
console.log(score);  // 10
```

## 10. Ternary Operator

The ternary operator is a **short form of if-else**. It is the only operator that takes **three** operands.

```
condition ? valueIfTrue : valueIfFalse
```

```js
let marks = 72;
let result = marks >= 35 ? "Pass" : "Fail";

console.log(result);   // Pass
```

**The same code with if-else:**

```js
let result;
if (marks >= 35) {
  result = "Pass";
} else {
  result = "Fail";
}
```

**Key points:**
- Great for **simple, one-line decisions**.
- Avoid nesting many ternaries. It makes the code hard to read.

```js
// ❌ Hard to read
let grade = marks > 90 ? "A" : marks > 75 ? "B" : marks > 50 ? "C" : "D";
```

## 11. Operator Precedence and Associativity

When one line has **many operators**, which one runs first?

### Precedence: who goes first

Just like the **BODMAS** rule in school maths, JavaScript has an order.

```js
console.log(2 + 3 * 4);     // 14, not 20 (* runs before +)
console.log((2 + 3) * 4);   // 20 (brackets run first)
```

**Common operators, from highest to lowest priority:**

| Priority | Operators | Name |
|----------|-----------|------|
| 1 (highest) | `( )` | Grouping (brackets) |
| 2 | `x++` `x--` | Postfix |
| 3 | `!` `++x` `--x` `+x` `-x` `typeof` | Unary |
| 4 | `**` | Exponent |
| 5 | `*` `/` `%` | Multiply, Divide, Remainder |
| 6 | `+` `-` | Add, Subtract |
| 7 | `<<` `>>` `>>>` | Bit shifts |
| 8 | `<` `<=` `>` `>=` | Relational |
| 9 | `==` `!=` `===` `!==` | Equality |
| 10 | `&` | Bitwise AND |
| 11 | `^` | Bitwise XOR |
| 12 | `\|` | Bitwise OR |
| 13 | `&&` | Logical AND |
| 14 | `\|\|` `??` | Logical OR, Nullish |
| 15 | `? :` | Ternary |
| 16 (lowest) | `=` `+=` `-=` etc. | Assignment |

### Associativity: which direction when the priority is the same

When two operators have the **same priority**, associativity decides the direction.

**Left to right** (most operators):

```js
console.log(20 - 5 - 3);   // 12 → (20 - 5) - 3
console.log(20 / 2 / 5);   // 2  → (20 / 2) / 5
```

**Right to left** (`**`, assignment, and ternary):

```js
console.log(2 ** 3 ** 2);   // 512 → 2 ** (3 ** 2) = 2 ** 9

let a, b, c;
a = b = c = 10;             // c = 10 first, then b, then a
console.log(a, b, c);       // 10 10 10
```

> **Best tip:** You don't need to memorise the whole table. **Use brackets `( )`** when in doubt. They make your code clear for everyone.

---

## Key Takeaways

- **Operators** are symbols that perform actions on values, like maths, comparing, and combining conditions.
- JavaScript has **no integer division**. Use `Math.trunc()` or `Math.floor()`. With `%`, the answer takes the **sign of the left number**.
- `+` **adds** numbers but **joins** strings. If any side is a string, the result is a string.
- Use `===` for comparing, `&&` / `||` / `??` for combining conditions, and the ternary `? :` for short decisions.
- **Precedence** decides which operator runs first, and **associativity** decides the direction. When in doubt, use brackets.
