# forEach Loop

Imagine a teacher distributing **exam results** in class. 📄

She picks up the pile of answer sheets and, for **each** sheet, does the same thing: calls the student's name and hands it over. She doesn't count or skip. She just says: *"For each sheet in this pile, do this."*

JavaScript arrays have a built-in method that works exactly like this. It is called **`forEach()`**.

::js-playground
```js
let students = ["Aarav", "Diya", "Kabir"];

students.forEach(function (student) {
  console.log("Here is your result, " + student);
});
```
::

## What Is forEach?

**`forEach()` is an array method that runs a function once for every item in the array, from the first item to the last.**

Unlike `for`, `while`, or `for...of`, which are **loop statements**, `forEach()` is a **method**. You call it **on an array** using a dot:

```js
array.forEach(...)
```

And instead of writing code inside `{ }` directly, you give `forEach()` a **function**. This function is called a **callback function**. JavaScript "calls it back" for each item.

> **Callback function** = a function that you give to another function, so it can run it later.

Think of it like giving instructions to a helper: *"Here is a list of tasks, and here is **what to do** with each one."* The helper (`forEach`) goes through the list, and your instructions (the callback) run for every item.

## Syntax

```js
array.forEach(function (item, index, array) {
  // code to run for each item
});
```

The callback function can receive **three values**:

| Parameter | Meaning | Required? |
|-----------|---------|-----------|
| `item` | The **current item** | ✅ Usually used |
| `index` | The **position** of the current item (starts from 0) | Optional |
| `array` | The **whole array** itself | Optional (rarely used) |

You can use **any names** for these parameters. Only the **order** matters: item first, then index, then array.

---

## Your First forEach

::js-playground
```js
let fruits = ["Mango", "Banana", "Apple"];

fruits.forEach(function (fruit) {
  console.log(fruit);
});
```
::

### How It Works, Step by Step

| Round | `fruit` | Action |
|-------|---------|--------|
| 1 | `"Mango"` | The callback runs → prints Mango |
| 2 | `"Banana"` | The callback runs → prints Banana |
| 3 | `"Apple"` | The callback runs → prints Apple |
| — | No more items | **forEach ends** |

No counter, no condition, no `.length`. `forEach()` handles everything for you!

---

## Shorter Way: Arrow Functions

Most developers write the callback as an **arrow function** `=>`, which is shorter and cleaner.

::js-playground
```js
let fruits = ["Mango", "Banana", "Apple"];

// Normal function
fruits.forEach(function (fruit) {
  console.log(fruit);
});

// Arrow function (same result)
fruits.forEach((fruit) => {
  console.log(fruit);
});

// Even shorter: a one-line arrow function
fruits.forEach((fruit) => console.log(fruit));
```
::

All three give the **same output**. We will learn arrow functions in detail in the **Functions** lesson. For now, just read `(fruit) => { ... }` as: *"take `fruit`, and do this."*

## Using the Index

The **second parameter** gives you the position of each item.

::js-playground
```js
let toppers = ["Ananya", "Rohan", "Kavya"];

toppers.forEach((name, index) => {
  console.log(`Rank ${index + 1}: ${name} 🏆`);
});
```
::

Remember, the index **starts from 0**, so we add `1` to show ranks starting from 1.

> **Compare:** In `for...of`, you need `.entries()` to get the index. In `forEach()`, you get it **for free**. 👍

---

## Using the Third Parameter (array)

The third parameter gives you the **whole array**. It is useful when you need to look at other items, like the next or previous one.

::js-playground
```js
let stations = ["Delhi", "Agra", "Gwalior", "Bhopal"];

stations.forEach((station, index, allStations) => {
  if (index < allStations.length - 1) {
    console.log(`${station} ➡️ ${allStations[index + 1]}`);
  }
});
```
::

## Real-Life Examples

### Example 1: Calculating a shopping bill 🛒

::js-playground
```js
let cart = [499, 1299, 250, 80];
let total = 0;

cart.forEach((price) => {
  total += price;
});

console.log("Total bill: ₹" + total);   // Total bill: ₹2128
```
::

### Example 2: Printing a bill with item numbers 🧾

::js-playground
```js
let items = ["Paneer Tikka", "Butter Naan", "Dal Makhani", "Lassi"];

console.log("---- ORDER ----");

items.forEach((item, i) => {
  console.log(`${i + 1}. ${item}`);
});
```
::

### Example 3: Checking pass or fail ✅❌

::js-playground
```js
let marks = [78, 32, 91, 28];

marks.forEach((mark, i) => {
  let result = mark >= 35 ? "Pass ✅" : "Fail ❌";
  console.log(`Student ${i + 1}: ${mark} → ${result}`);
});
```
::

### Example 4: Working with an array of objects 🍕

This is **very common** in real projects, for example when showing orders from a food delivery app.

::js-playground
```js
let orders = [
  { id: 101, item: "Biryani", amount: 250 },
  { id: 102, item: "Pizza", amount: 399 },
  { id: 103, item: "Dosa", amount: 120 }
];

let totalSales = 0;
console.log("---- ORDER ----");
orders.forEach((order) => {
  console.log(`Order #${order.id}: ${order.item} - ₹${order.amount}`);
  totalSales += order.amount;
});
console.log("---------------");
console.log("Total sales: ₹" + totalSales);
console.log("---------------");
```
::


### Example 5: Using a separate named function

You can also write the function **separately** and pass its **name** to `forEach()`.

::js-playground
```js
function sendWish(friend) {
  console.log(`Happy Holi, ${friend}! 🎨`);
}

let friends = ["Meera", "Arjun", "Tanya"];

friends.forEach(sendWish);
```
::

**Note:** Write `forEach(sendWish)`, **not** `forEach(sendWish())`. Adding `()` would run the function immediately, instead of giving it to `forEach`.

## Changing Array Items with forEach

### With primitive values: use the index

Changing the `item` variable does **not** change the array, because it is only a copy.

::js-playground
```js
let prices = [100, 200, 300];

prices.forEach((price) => {
  price = price * 2;   // ❌ only changes the copy
});

console.log(prices);   // [100, 200, 300]
```
::

**✅ Fix:** Use the index to update the original array:

::js-playground
```js
let prices = [100, 200, 300];
prices.forEach((price, i, arr) => {
  arr[i] = price * 2;
});

console.log(prices);   // [200, 400, 600] ✅
```
::

### With objects: you can change their properties directly

::js-playground
```js
let products = [
  { name: "Pen", price: 10 },
  { name: "Notebook", price: 50 }
];

products.forEach((product) => {
  product.price += 5;   // ✅ changes the original object
});

console.log(products);
// [{ name: "Pen", price: 15 }, { name: "Notebook", price: 55 }]
```
::

> **Tip:** If you want to create a **new array** with changed values, `map()` is a better choice. You will learn it in the **Array Methods** lesson.


## ⚠️ Important Things to Know About forEach

### 1. You cannot use `break` or `continue`

`forEach()` **always goes through every item**. There is no way to stop it early using `break` or `continue`.

::js-playground
```js
let numbers = [1, 2, 3, 4, 5];

numbers.forEach((num) => {
  if (num === 3) break;   // ❌ SyntaxError: Illegal break statement
  console.log(num);
});
```
::

**What about `return`?** Inside `forEach()`, `return` only **skips the current item**, like `continue`. It does **not** stop the loop.

::js-playground
```js
let numbers = [1, 2, 3, 4, 5];
numbers.forEach((num) => {
  if (num === 3) return;   // skips only 3
  console.log(num);
});
// 1 2 4 5
```
::

**✅ Need to stop early?** Use `for...of` instead:

::js-playground
```js
let numbers = [1, 2, 3, 4, 5];
for (const num of numbers) {
  if (num === 3) break;   // ✅ works
  console.log(num);
}
// 1 2
```
::

### 2. forEach always returns `undefined`

`forEach()` **does not give back** any value. It just runs the function for each item.

::js-playground
```js
let result = [1, 2, 3].forEach((n) => n * 2);
console.log(result);   // undefined
```
::

If you want a **new array** as the result, use `map()` instead:

::js-playground
```js
let doubled = [1, 2, 3].map((n) => n * 2);
console.log(doubled);   // [2, 4, 6] ✅
```
::

### 3. It works only on arrays (and a few array-like lists)

`forEach()` is an **array method**, so it doesn't work directly on plain objects or strings.

```js
let student = { name: "Ravi", age: 20 };
student.forEach(...);   // ❌ TypeError: student.forEach is not a function

"Hello".forEach(...);   // ❌ TypeError
```

**✅ Fix for objects:** Convert them to an array first:

::js-playground
```js
let student = { name: "Ravi", age: 20 };
Object.entries(student).forEach(([key, value]) => {
  console.log(`${key}: ${value}`);
});
```
::

**✅ Fix for strings:** Split the string into an array of characters:

::js-playground
```js
[..."Hello"].forEach((char) => console.log(char));
```
::

Map and Set also have their own `forEach()` method, which you will see in later lessons.

### 4. Empty slots are skipped

If an array has **empty slots**, `forEach()` skips them silently.

::js-playground
```js
let data = [1, , 3];   // the middle slot is empty

data.forEach((item) => console.log(item));
```
::

### 5. It doesn't wait for async tasks

`forEach()` does **not** wait for tasks like fetching data from the internet to finish. If you need to wait, use `for...of` with `await`. You will learn this in the **Async JavaScript** lesson.


## forEach vs for...of vs for Loop

The same task, written three ways:

::js-playground
```js
let cities = ["Delhi", "Pune", "Kochi"];

// 1. Normal for loop
for (let i = 0; i < cities.length; i++) {
  console.log(cities[i]);
}

// 2. for...of
for (const city of cities) {
  console.log(city);
}

// 3. forEach
cities.forEach((city) => console.log(city));
```
::

| Point | `for` | `for...of` | `forEach()` |
|-------|-------|------------|-------------|
| Type | Loop statement | Loop statement | **Array method** |
| Gives the index | ✅ Manually (`i`) | Only with `.entries()` | ✅ Automatically |
| `break` / `continue` | ✅ Yes | ✅ Yes | ❌ No |
| Works on | Anything with an index | Arrays, strings, Map, Set | Arrays (and Map, Set) |
| Returns a value | — | — | Always `undefined` |
| Waits for `await` | ✅ Yes | ✅ Yes | ❌ No |
| Code style | Longer | Clean | Short and clean |

**Simple way to choose:**
- **Doing something with every array item, with no stopping needed?** → `forEach()` ✅
- **Might need to stop early or skip items?** → `for...of`
- **Need full control over the counter or steps?** → normal `for`

---

## Common Mistakes to Avoid

| Mistake | Problem | Fix |
|---------|---------|-----|
| Using `break` or `continue` | ❌ SyntaxError | Use `for...of` |
| Expecting `return` to stop the loop | It only skips the current item | Use `for...of` with `break` |
| Storing the result of `forEach()` | Always `undefined` | Use `map()` to get a new array |
| Calling `forEach` on an object or string | ❌ TypeError | Use `Object.entries()` or `[...str]` |
| Writing `forEach(myFunc())` | Runs the function immediately | Write `forEach(myFunc)` |
| Changing `item` to update the array | The original array is not changed | Use `arr[index]` |

---

## Quick Summary Table

| Task | Code |
|------|------|
| Basic forEach | `arr.forEach((item) => { })` |
| With index | `arr.forEach((item, i) => { })` |
| With the whole array | `arr.forEach((item, i, arr) => { })` |
| Using a named function | `arr.forEach(myFunction)` |
| Update primitive items | `arr.forEach((v, i, a) => a[i] = ...)` |
| Loop through an object | `Object.entries(obj).forEach(([k, v]) => { })` |
| Skip one item | `if (condition) return;` |

## Key Takeaways

- **`forEach()`** is an **array method** that runs a **callback function** once for **every item** in the array.
- The callback receives the **item**, the **index**, and the **whole array**, in that order.
- It is **short and clean**, and you get the **index automatically**.
- You **cannot use `break` or `continue`**, and `return` only skips the current item. Use `for...of` when you need to stop early.
- `forEach()` always returns **`undefined`**. Use **`map()`** when you need a new array.
