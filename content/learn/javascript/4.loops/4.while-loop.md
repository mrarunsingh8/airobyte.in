# While Loop

Imagine you are filling a bucket with water from a tap. 🪣

You don't count how many mugs of water to pour. You simply **keep pouring while the bucket is not full**. The moment it is full, you stop.

In the last lesson, we learned the **for loop**, which is great when you **know** how many times to repeat something, like "print 10 times."

But sometimes you **don't know** the number of repeats in advance. You just want to **keep going until something happens**. For this, JavaScript gives us the **while loop**.

## What Is a While Loop?

**A while loop repeats a block of code again and again, as long as a condition is true.**

It keeps asking one question before every round: **"Is the condition still true?"**

- **Yes** → run the code again.
- **No** → stop the loop.

## Syntax

```js
while (condition) {
  // code to repeat
}
```

Unlike the for loop, the while loop has **only one part** inside the brackets: the **condition**.

So where do the starting value and the update go?

- **Starting value** → created **before** the loop
- **Update** → written **inside** the loop

::js-playground
```js
let i = 1;              // 1. starting value (before)

while (i <= 5) {        // 2. condition
  console.log(i);
  i++;                  // 3. update (inside)
}
```
::

---

## Your First While Loop

::js-playground
```js
let count = 1;

while (count <= 5) {
  console.log("Count: " + count);
  count++;
}

console.log("Loop finished!");
```
::

### How It Works, Step by Step

| Step | Value of `count` | Condition `count <= 5` | Action |
|------|-----------------|------------------------|--------|
| Round 1 | `1` | ✅ true | Print, then `count++` |
| Round 2 | `2` | ✅ true | Print, then `count++` |
| Round 3 | `3` | ✅ true | Print, then `count++` |
| Round 4 | `4` | ✅ true | Print, then `count++` |
| Round 5 | `5` | ✅ true | Print, then `count++` |
| Check | `6` | ❌ false | **Loop stops** |

**The flow:**

```
Check condition → true → Run code → Check condition → true → Run code → ...
       ↓ (false)
   Exit the loop
```

**Key points:**
- The condition is checked **before** every round.
- If the condition is **false from the very start**, the loop **never runs**, not even once:

::js-playground
```js
let x = 10;

while (x < 5) {
  console.log("This will never print");
}
```
::

## Real-Life Examples

The while loop shines when the **number of rounds depends on a situation**.

### Example 1: Saving money for a new phone 📱

You save ₹2,000 every month. How many months will it take to buy a phone worth ₹15,000?

::js-playground
```js
let savings = 0;
let months = 0;
const phonePrice = 15000;

while (savings < phonePrice) {
  savings += 2000;
  months++;
}

console.log(`You can buy the phone after ${months} months!`);
console.log(`Total saved: ₹${savings}`);
```
::

**Output:**

```
You can buy the phone after 8 months!
Total saved: ₹16000
```

We didn't know it would take **8 months**. The loop figured it out for us!

### Example 2: Mobile battery charging 🔋

::js-playground
```js
let battery = 20;

while (battery < 100) {
  battery += 20;
  console.log("Charging... " + battery + "%");
}

console.log("Fully charged! ✅");
```
::

### Example 3: Counting the digits in a number

::js-playground
```js
let number = 98765;
let digits = 0;

while (number > 0) {
  number = Math.trunc(number / 10);   // remove the last digit
  digits++;
}

console.log("Total digits: " + digits);   // Total digits: 5
```
::

### Example 4: Reversing a number

::js-playground
```js
let num = 1234;
let reversed = 0;

while (num > 0) {
  let lastDigit = num % 10;              // take the last digit
  reversed = reversed * 10 + lastDigit;  // add it to the reversed number
  num = Math.trunc(num / 10);            // remove the last digit
}

console.log(reversed);   // 4321
```
::

### Example 5: Tea shop orders ☕

Serve customers until the milk runs out.

::js-playground
```js
let milk = 1000;          // in ml
const perCup = 150;
let cupsServed = 0;

while (milk >= perCup) {
  milk -= perCup;
  cupsServed++;
}

console.log(`Cups served: ${cupsServed}`);   // Cups served: 6
console.log(`Milk left: ${milk} ml`);        // Milk left: 100 ml
```
::

## Looping Through an Array with While

You can also go through an array using a while loop.

::js-playground
```js
let cities = ["Delhi", "Mumbai", "Chennai", "Kolkata"];
let i = 0;

while (i < cities.length) {
  console.log(cities[i]);
  i++;
}
```
::

> **Tip:** For arrays, the **for loop** is usually cleaner, because all three parts are in one line. Use `while` when the stopping point is **not fixed**.

## Infinite Loops ⚠️

This is the **most common mistake** with while loops.

If you **forget to update** the variable, the condition **stays true forever**, and the loop never ends. This can **freeze your browser**!

```js
let i = 1;

while (i <= 5) {
  console.log(i);
  // ❌ forgot i++ → prints 1 forever!
}
```

**Another example:**

```js
let i = 10;

while (i > 0) {
  console.log(i);
  i++;   // ❌ wrong direction → i keeps growing, it never reaches 0
}
```

**How to avoid infinite loops:**
- ✅ Always **update** the variable inside the loop.
- ✅ Make sure the update moves **toward** making the condition false.
- ✅ Before running, ask yourself: *"When will this loop stop?"*

> **If your browser freezes:** Close the tab. In Node.js, press **Ctrl + C** to stop the program.

### Intentional infinite loops with `break`

Sometimes developers write `while (true)` **on purpose** and stop it using `break` when a condition is met.

::js-playground
```js
let attempts = 0;

while (true) {
  attempts++;
  console.log("Attempt " + attempts);

  if (attempts === 3) {
    console.log("Stopping now");
    break;   // exits the loop
  }
}
```
::

We will learn more about `break` in the **Break & Continue** lesson.

## For Loop vs While Loop

Both loops can do the same work. The difference is **when** to use which.

| Point | For Loop | While Loop |
|-------|----------|------------|
| Best when | You **know** how many times to repeat | You **don't know** how many times |
| Parts in brackets | 3 (start; condition; update) | 1 (condition only) |
| Start value | Inside the brackets | Before the loop |
| Update | Inside the brackets | Inside the loop body |
| Example | Print a table from 1 to 10 | Keep saving until you reach the goal |

**The same task, written both ways:**

::js-playground
```js
// For loop
for (let i = 1; i <= 3; i++) {
  console.log(i);
}

// While loop
let j = 1;
while (j <= 3) {
  console.log(j);
  j++;
}
```
::

**Simple way to remember:**
- **"Do this 10 times"** → `for` loop
- **"Keep doing this until..."** → `while` loop

## Common Mistakes to Avoid

| Mistake | Problem | Fix |
|---------|---------|-----|
| Forgetting the update (`i++`) | Infinite loop | Always update the variable inside the loop |
| Updating in the wrong direction | Infinite loop | Counting up → `++`, counting down → `--` |
| Putting a semicolon after `while (...)` | The loop body never runs properly | Remove the `;` |
| Creating the variable inside the loop | It resets every round → infinite loop | Create it **before** the loop |

**Example of the last mistake:**

```js
while (i <= 5) {
  let i = 1;   // ❌ resets to 1 every time
  i++;
}
```

## Quick Summary Table

| Concept | Example |
|---------|---------|
| Basic while loop | `while (i <= 5) { ... i++; }` |
| Loop until a goal | `while (savings < target) { ... }` |
| Loop through an array | `while (i < arr.length) { ... i++; }` |
| Intentional infinite loop | `while (true) { if (...) break; }` |

## Key Takeaways

- A **while loop** repeats code **as long as the condition is true**.
- It is best when you **don't know in advance** how many times the loop should run.
- Create the **starting value before** the loop and **update it inside** the loop.
- If the condition is **false at the start**, the loop **doesn't run at all**.
- Always make sure the loop can **stop**. Forgetting the update creates an **infinite loop**.
