# Do-While Loop

Think about eating at a new restaurant. 🍛

You **first taste** the food, and **then** decide: *"Is it good? Should I order more?"*

You can't decide whether you like the food **before tasting it**. You must try it **at least once**.

In the last lesson, the **while loop** checked the condition **first**, and then ran the code. So if the condition was false at the start, the code **never ran at all**.

But sometimes we want the code to run **at least once**, no matter what, and **then** check the condition. For this, JavaScript gives us the **do-while loop**.

## What Is a Do-While Loop?

**A do-while loop runs the code first, and then checks the condition. If the condition is true, it repeats. So the code always runs at least once.**

- **while loop:** *Check first, then run.* 🤔 → 🏃
- **do-while loop:** *Run first, then check.* 🏃 → 🤔

## Syntax

```js
do {
  // code to repeat
} while (condition);
```

**Key points about the syntax:**
- The code block `{ }` comes **first**, after the keyword `do`.
- The `while (condition)` comes **at the end**.
- Notice the **semicolon `;`** after `while (condition)`. It is required here, unlike in the normal while loop!

---

## Your First Do-While Loop

```js
let count = 1;

do {
  console.log("Count: " + count);
  count++;
} while (count <= 5);

console.log("Loop finished!");
```

**Output:**

```
Count: 1
Count: 2
Count: 3
Count: 4
Count: 5
Loop finished!
```

### How It Works, Step by Step

| Step | Action | Value of `count` | Condition `count <= 5` |
|------|--------|-----------------|------------------------|
| Round 1 | Print "Count: 1", then `count++` | becomes `2` | ✅ true → repeat |
| Round 2 | Print "Count: 2", then `count++` | becomes `3` | ✅ true → repeat |
| Round 3 | Print "Count: 3", then `count++` | becomes `4` | ✅ true → repeat |
| Round 4 | Print "Count: 4", then `count++` | becomes `5` | ✅ true → repeat |
| Round 5 | Print "Count: 5", then `count++` | becomes `6` | ❌ false → **stop** |

**The flow:**

```
Run code → Check condition → true → Run code → Check condition → ...
                  ↓ (false)
              Exit the loop
```

---

## The Big Difference: It Always Runs at Least Once

Let us see what happens when the condition is **false from the very beginning**.

### With a while loop

```js
let x = 10;

while (x < 5) {
  console.log("While loop ran");
}
// Output: (nothing)
```

The condition `10 < 5` is false, so the code **never runs**.

### With a do-while loop

```js
let y = 10;

do {
  console.log("Do-while loop ran");
} while (y < 5);
// Output: Do-while loop ran
```

The code runs **once first**, and **then** JavaScript checks `10 < 5`. It is false, so the loop stops. But the code **already ran one time**!

> **Remember:** A do-while loop runs **at least once**, even if the condition is false from the start.

## Real-Life Examples

The do-while loop is perfect when you **must do something first** and then decide whether to repeat it.

### Example 1: ATM PIN entry 🏧

The ATM must **ask for the PIN at least once**. If it is wrong, it asks again, up to 3 attempts.

```js
const correctPin = 4321;
let enteredPins = [1111, 2222, 4321];   // PINs the user types, one by one
let attempt = 0;
let pin;

do {
  pin = enteredPins[attempt];
  attempt++;
  console.log(`Attempt ${attempt}: You entered ${pin}`);
} while (pin !== correctPin && attempt < 3);

if (pin === correctPin) {
  console.log("✅ PIN correct. Welcome!");
} else {
  console.log("❌ Card blocked. Too many wrong attempts.");
}
```

**Output:**

```
Attempt 1: You entered 1111
Attempt 2: You entered 2222
Attempt 3: You entered 4321
✅ PIN correct. Welcome!
```

The ATM **has to ask at least once**, which makes this a perfect fit for do-while.

### Example 2: Menu-driven program 📋

A menu should be **shown at least once**, and then repeat until the user chooses "Exit."

```js
let choices = [1, 2, 3];   // options the user picks, one by one
let index = 0;
let choice;

do {
  console.log("\n--- MENU ---");
  console.log("1. Check Balance");
  console.log("2. Recharge");
  console.log("3. Exit");

  choice = choices[index];
  index++;
  console.log("You chose: " + choice);

  if (choice === 1) {
    console.log("Your balance is ₹250");
  } else if (choice === 2) {
    console.log("Recharge successful!");
  }
} while (choice !== 3);

console.log("Thank you! 👋");
```

The menu always shows **at least once**, even if the user wants to exit right away.

### Example 3: Rolling a dice until you get 6 🎲

In games like Ludo, you **must roll at least once**, and you keep rolling until you get a 6.

```js
let dice;
let rolls = 0;

do {
  dice = Math.floor(Math.random() * 6) + 1;   // random number from 1 to 6
  rolls++;
  console.log("Rolled: " + dice);
} while (dice !== 6);

console.log(`Got a 6 after ${rolls} roll(s)! 🎉`);
```

**Sample output** (it changes every time):

```
Rolled: 3
Rolled: 1
Rolled: 6
Got a 6 after 3 roll(s)! 🎉
```

We don't know how many rolls it will take, but we know we must **roll at least once**.

### Example 4: Adding the digits of a number

```js
let number = 4829;
let sum = 0;

do {
  sum += number % 10;                // add the last digit
  number = Math.trunc(number / 10);  // remove the last digit
} while (number > 0);

console.log("Sum of digits: " + sum);   // Sum of digits: 23
```

**Why do-while here?** Even if the number is `0`, it has **one digit** that should be processed. A do-while makes sure it runs at least once.

## Infinite Loops ⚠️

Just like the while loop, if the condition **never becomes false**, the loop **never stops**.

```js
let i = 1;

do {
  console.log(i);
  // ❌ forgot i++ → runs forever!
} while (i <= 5);
```

**How to avoid it:**
- ✅ Always **update** the variable inside the loop.
- ✅ Make sure the update moves **toward** making the condition false.

## While vs Do-While vs For

| Point | For Loop | While Loop | Do-While Loop |
|-------|----------|------------|---------------|
| Condition checked | Before each round | Before each round | **After** each round |
| Minimum runs | 0 | 0 | **1** |
| Best when | Number of repeats is known | Number of repeats is unknown | Code must run **at least once** |
| Semicolon at end? | No | No | **Yes** `while (...);` |
| Example | Print a table from 1 to 10 | Save money until a goal | Show a menu, ask for a PIN |

**Simple way to remember:**
- **"Do this 10 times"** → `for`
- **"Keep doing this while..."** → `while`
- **"Do this once, then repeat if needed"** → `do-while`

## Common Mistakes to Avoid

### ❌ Mistake 1: Forgetting the semicolon

```js
do {
  console.log("Hello");
} while (false)    // ⚠️ semicolon missing
```

It often still works, but **always add the semicolon** to keep your code clean and safe:

```js
} while (false);   // ✅
```

### ❌ Mistake 2: Using do-while when the code should not run

```js
let cartItems = 0;

do {
  console.log("Processing payment...");   // ❌ runs even with an empty cart!
} while (cartItems > 0);
```

If the code **should not run** when the condition is false, use a normal **while loop** instead.

### ❌ Mistake 3: Declaring the variable inside the loop

```js
do {
  let i = 1;   // ❌ resets every round
  i++;
} while (i <= 5);   // ❌ ReferenceError: i is not defined
```

Variables used in the condition must be created **before** the `do` block.

|---------|---------|
| Basic do-while | `do { ... i++; } while (i <= 5);` |
| Runs once even if false | `do { ... } while (false);` |
| Repeat until the correct input | `do { ask(); } while (input !== correct);` |
| Menu loop | `do { showMenu(); } while (choice !== exit);` |

## Key Takeaways

- A **do-while loop** runs the code **first**, then checks the condition.
- It always runs **at least once**, even if the condition is false from the start.
- It is perfect for **menus**, **PIN or password entry**, **input validation**, and **games**.
- Don't forget the **semicolon `;`** after `while (condition)`.
- Always **update** the loop variable to avoid **infinite loops**.
