# for...of Loop

Imagine a **bowl of gol gappe** (pani puri) in front of you. 😋

You don't count *"Puri number 0, puri number 1, puri number 2..."* You just pick **one puri**, eat it, pick the **next one**, eat it, and keep going until the bowl is empty.

That is exactly how the **`for...of` loop** works. It picks **each item one by one** from a list, without caring about position numbers.

In the For Loop lesson, we went through an array like this:

```js
let fruits = ["Mango", "Banana", "Apple"];

for (let i = 0; i < fruits.length; i++) {
  console.log(fruits[i]);
}
```

We had to manage `i`, write the condition, use `.length`, and access `fruits[i]`. That is **four things** to take care of, and four chances to make mistakes.

With `for...of`, the same work becomes:

```js
for (const fruit of fruits) {
  console.log(fruit);
}
```

Clean, short, and easy to read! ✨

## What Is a for...of Loop?

**A `for...of` loop goes through each value of an iterable (like an array or string), one at a time, from start to end.**

An **iterable** is anything that can be **gone through one item at a time**. In JavaScript, these include:

| Iterable | Example |
|----------|---------|
| Array | `["Red", "Green", "Blue"]` |
| String | `"Hello"` |
| Map | A list of key-value pairs |
| Set | A list of unique values |

> **Not iterable:** plain objects like `{ name: "Ravi" }`. We will see how to handle them later in this lesson.

## Syntax

```js
for (const item of iterable) {
  // use item
}
```

| Part | Meaning |
|------|---------|
| `item` | A variable that holds **one value** in each round. You can name it anything. |
| `of` | The keyword that means "go through the values **of** this list" |
| `iterable` | The array, string, Map, or Set you want to loop through |

---

## Your First for...of Loop

```js
let colors = ["Red", "Green", "Blue"];

for (const color of colors) {
  console.log(color);
}
```

**Output:**

```
Red
Green
Blue
```

### How It Works, Step by Step

| Round | Value of `color` |
|-------|-----------------|
| 1 | `"Red"` |
| 2 | `"Green"` |
| 3 | `"Blue"` |
| — | No more values → **loop stops** |

**Key points:**
- Read it like English: *"for each **color** of **colors**."*
- The loop **stops automatically** after the last item. No infinite loop worries!
- There is **no index to manage**, so there are **no off-by-one errors**.

---

## `const` or `let`?

Each round creates a **fresh** variable, so you can safely use `const`.

```js
for (const city of ["Delhi", "Mumbai"]) {
  console.log(city);   // ✅ works fine
}
```

Use `let` only if you want to **change the variable inside** the loop:

```js
for (let price of [100, 200]) {
  price = price + 18;   // adding GST
  console.log(price);   // 118, 218
}
```

> **Tip:** Use `const` by default, just like with normal variables.

## Part 1: for...of with Arrays

This is the **most common use** of `for...of`.

### Example 1: Calculating a shopping bill 🛒

```js
let cart = [499, 1299, 250, 80];
let total = 0;

for (const price of cart) {
  total += price;
}

console.log("Total bill: ₹" + total);   // Total bill: ₹2128
```

### Example 2: Finding the highest score 🏏

```js
let runs = [45, 82, 110, 23, 67];
let highest = runs[0];

for (const run of runs) {
  if (run > highest) {
    highest = run;
  }
}

console.log("Highest score: " + highest);   // Highest score: 110
```

### Example 3: Counting passed students ✅

```js
let marks = [78, 32, 91, 45, 28, 66];
let passed = 0;
let failed = 0;

for (const mark of marks) {
  if (mark >= 35) {
    passed++;
  } else {
    failed++;
  }
}

console.log(`Passed: ${passed}, Failed: ${failed}`);
// Passed: 4, Failed: 2
```

### Example 4: Sending festival wishes 🪔

```js
let friends = ["Anjali", "Karan", "Sameer", "Divya"];

for (const friend of friends) {
  console.log(`Happy Diwali, ${friend}! 🪔✨`);
}
```

**Output:**

```
Happy Diwali, Anjali! 🪔✨
Happy Diwali, Karan! 🪔✨
Happy Diwali, Sameer! 🪔✨
Happy Diwali, Divya! 🪔✨
```

## Part 2: for...of with Strings

`for...of` goes through a string **one character at a time**.

```js
let word = "NAMASTE";

for (const letter of word) {
  console.log(letter);
}
```

**Output:**

```
N
A
M
A
S
T
E
```

### Example: Counting vowels

```js
let city = "Ahmedabad";
let vowels = 0;

for (const char of city.toLowerCase()) {
  if ("aeiou".includes(char)) {
    vowels++;
  }
}

console.log("Vowels in " + city + ": " + vowels);   // Vowels in Ahmedabad: 4
```

### Example: Reversing a word

```js
let word = "India";
let reversed = "";

for (const char of word) {
  reversed = char + reversed;   // add each letter at the front
}

console.log(reversed);   // aidnI
```

### Bonus: It handles emojis correctly! 🎉

```js
let mood = "Hi😊";

for (const char of mood) {
  console.log(char);
}
// H
// i
// 😊
```

A normal `for` loop with an index can **break emojis into strange symbols**, but `for...of` reads them correctly. 👍

## Part 3: Getting the Index with `.entries()`

`for...of` gives you only the **value**. What if you also need the **position**?

Use `.entries()`. It gives you the **index and the value** together.

```js
let toppers = ["Ananya", "Rohan", "Kavya"];

for (const [index, name] of toppers.entries()) {
  console.log(`Rank ${index + 1}: ${name}`);
}
```

**Output:**

```
Rank 1: Ananya
Rank 2: Rohan
Rank 3: Kavya
```

**How it works:**
- `.entries()` gives pairs like `[0, "Ananya"]`, `[1, "Rohan"]`, and so on.
- `[index, name]` **unpacks** each pair into two variables. This is called **destructuring**, and you will learn more about it later.

## Part 4: for...of with Map and Set

You will learn **Map** and **Set** in detail later, but here is a quick look, because `for...of` works perfectly with them.

### Set: a list of unique values

```js
let visitedCities = new Set(["Goa", "Jaipur", "Goa", "Shimla"]);

for (const city of visitedCities) {
  console.log(city);
}
// Goa
// Jaipur
// Shimla   ← the duplicate "Goa" was removed automatically
```

### Map: key-value pairs (like a better object)

```js
let trainTimes = new Map([
  ["Rajdhani", "4:30 PM"],
  ["Shatabdi", "6:00 AM"],
  ["Duronto", "11:15 PM"]
]);

for (const [train, time] of trainTimes) {
  console.log(`${train} departs at ${time}`);
}
```

**Output:**

```
Rajdhani departs at 4:30 PM
Shatabdi departs at 6:00 AM
Duronto departs at 11:15 PM
```

## Part 5: for...of with Objects (the Right Way)

Plain objects are **not iterable**, so `for...of` **cannot** loop through them directly.

```js
let student = { name: "Ravi", age: 20, city: "Jaipur" };

for (const value of student) {   // ❌ TypeError: student is not iterable
  console.log(value);
}
```

**✅ Fix:** Convert the object into an array first, using these helper methods:

| Method | Gives you |
|--------|-----------|
| `Object.keys(obj)` | An array of **keys** |
| `Object.values(obj)` | An array of **values** |
| `Object.entries(obj)` | An array of **[key, value] pairs** |

```js
let student = { name: "Ravi", age: 20, city: "Jaipur" };

// Only the values
for (const value of Object.values(student)) {
  console.log(value);
}
// Ravi, 20, Jaipur

// Both key and value
for (const [key, value] of Object.entries(student)) {
  console.log(`${key}: ${value}`);
}
// name: Ravi
// age: 20
// city: Jaipur
```

> This is one of the **most popular** ways to loop through objects in modern JavaScript.

## Using break and continue with for...of

Unlike `forEach()`, `for...of` fully supports **`break`** and **`continue`**. 👍

### `break`: stop when found

```js
let parcels = ["Shoes", "Books", "Phone", "Watch"];

for (const parcel of parcels) {
  if (parcel === "Phone") {
    console.log("📱 Phone found! Delivering now.");
    break;
  }
  console.log("Checking: " + parcel);
}
```

**Output:**

```
Checking: Shoes
Checking: Books
📱 Phone found! Delivering now.
```

### `continue`: skip unwanted items

```js
let transactions = [500, -100, 2000, 0, 750];
let total = 0;

for (const amount of transactions) {
  if (amount <= 0) {
    continue;   // skip invalid amounts
  }
  total += amount;
}

console.log("Valid total: ₹" + total);   // Valid total: ₹3250
```

## Can You Change Array Items with for...of?

This depends on **what type** of items the array has.

### With primitive values (numbers, strings): ❌ No

The loop variable is only a **copy**. Changing it does **not** change the array.

```js
let prices = [100, 200, 300];

for (let price of prices) {
  price = price * 2;   // only the copy changes
}

console.log(prices);   // [100, 200, 300] (not changed!)
```

Remember the **photocopy** example from the Data Types lesson? Writing on the photocopy doesn't change the original.

**✅ Fix:** Use `.entries()` to get the index, and update using it:

```js
for (const [i, price] of prices.entries()) {
  prices[i] = price * 2;
}

console.log(prices);   // [200, 400, 600] ✅
```

### With objects: ✅ Yes, you can change their properties

Objects are **shared** (like a Google Doc), so changes **do** reach the original.

```js
let products = [
  { name: "Pen", price: 10 },
  { name: "Notebook", price: 50 }
];

for (const product of products) {
  product.price = product.price + 5;   // price increase
}

console.log(products);
// [{ name: "Pen", price: 15 }, { name: "Notebook", price: 55 }] ✅
```

## Looping Through an Array of Objects

This is **very common** in real projects, for example with data coming from a server.

```js
let orders = [
  { id: 101, item: "Biryani", amount: 250, delivered: true },
  { id: 102, item: "Pizza", amount: 399, delivered: false },
  { id: 103, item: "Dosa", amount: 120, delivered: true }
];

let pending = 0;

for (const order of orders) {
  let status = order.delivered ? "✅ Delivered" : "⏳ Pending";
  console.log(`#${order.id} ${order.item} - ₹${order.amount} - ${status}`);

  if (!order.delivered) {
    pending++;
  }
}

console.log(`\nPending orders: ${pending}`);
```

**Output:**

```
#101 Biryani - ₹250 - ✅ Delivered
#102 Pizza - ₹399 - ⏳ Pending
#103 Dosa - ₹120 - ✅ Delivered

Pending orders: 1
```

## Nested for...of Loops

You can put a `for...of` **inside** another one, for example for a **2D array** (an array of arrays).

```js
let cinemaSeats = [
  ["A1", "A2", "A3"],
  ["B1", "B2", "B3"]
];

for (const row of cinemaSeats) {
  let line = "";
  for (const seat of row) {
    line += seat + "  ";
  }
  console.log(line);
}
```

**Output:**

```
A1  A2  A3
B1  B2  B3
```

## for...of vs Other Loops

| Point | `for` | `for...of` | `for...in` | `forEach()` |
|-------|-------|------------|------------|-------------|
| Gives you | Index | **Value** | Key | Value + index |
| Works on | Anything with an index | Arrays, strings, Map, Set | Objects | Arrays only |
| `break` / `continue` | ✅ | ✅ | ✅ | ❌ |
| Index management | Manual | Not needed | Not needed | Not needed |
| Best for | Full control | **Reading lists** | Object keys | Quick array tasks |

**Simple way to choose:**
- **Going through the values of a list?** → `for...of` ✅
- **Going through the keys of an object?** → `for...in`
- **Need to control the counter or jump steps?** → normal `for`

> **Easy trick:** **`of`** → values **of** a list. **`in`** → keys **in** an object.

## Common Mistakes to Avoid

| Mistake | Problem | Fix |
|---------|---------|-----|
| Using `for...of` on a plain object | ❌ TypeError: not iterable | Use `Object.entries()` or `for...in` |
| Confusing `of` with `in` on arrays | `in` gives string indexes | Use `of` for array values |
| Changing the loop variable to update the array | The original array stays the same | Use `.entries()` with the index |
| Expecting the index automatically | `for...of` gives only values | Use `.entries()` |
| Using it on `null` or `undefined` | ❌ TypeError | Check that the value exists first |

## Quick Summary Table

| Task | Code |
|------|------|
| Loop through an array | `for (const item of arr) { }` |
| Loop through a string | `for (const char of str) { }` |
| Get index + value | `for (const [i, v] of arr.entries()) { }` |
| Loop through object values | `for (const v of Object.values(obj)) { }` |
| Loop through object key + value | `for (const [k, v] of Object.entries(obj)) { }` |
| Loop through a Map | `for (const [k, v] of map) { }` |
| Loop through a Set | `for (const v of set) { }` |

## Key Takeaways

- The **`for...of` loop** goes through each **value** of an iterable, like arrays, strings, Maps, and Sets.
- It is **clean and safe**: no index, no condition, no off-by-one errors, and it stops automatically.
- Use **`.entries()`** when you need both the **index and the value**.
- Plain objects are **not iterable**, so use `Object.keys()`, `Object.values()`, or `Object.entries()` with `for...of`.
- It supports **`break` and `continue`**, which makes it more flexible than `forEach()`.
