# Object Properties & Methods

Think about your **mobile phone**. 📱

- It **has** things: a brand, a colour, a battery percentage. → These are **properties**.
- It **can do** things: make a call, click a photo, play music. → These are **methods**.

JavaScript objects work the same way.

| | Meaning | Phone example |
|---|---------|---------------|
| **Property** | What an object **has** (data) | `brand`, `battery` |
| **Method** | What an object **can do** (a function) | `call()`, `charge()` |

::js-playground
```js
const phone = {
  brand: "Samsung",         // property
  battery: 40,              // property

  call(name) {              // method
    return `📞 Calling ${name}...`;
  }
};

console.log(phone.brand);          // Samsung
console.log(phone.call("Mummy"));  // 📞 Calling Mummy...
```
::

---

## Properties

A **property** is a `key: value` pair that stores **data** about the object.

::js-playground
```js
const student = {
  name: "Priya",
  age: 21,
  subjects: ["Maths", "Science"]
};

student.city = "Pune";   // add
student.age = 22;        // update
delete student.subjects; // delete

console.log(student);    // { name: "Priya", age: 22, city: "Pune" }
```
::

> You learned how to create, read, update, and delete properties in the previous lesson.

## Methods

A **method** is simply a **function stored inside an object**. You call it with a dot and brackets: `object.method()`.

### Two ways to write a method

::js-playground
```js
const calculator = {
  // 1. Full way
  add: function (a, b) {
    return a + b;
  },

  // 2. Short way (preferred ✅)
  multiply(a, b) {
    return a * b;
  }
};

console.log(calculator.add(5, 3));        // 8
console.log(calculator.multiply(5, 3));   // 15
```
::

> ⚠️ Don't forget the brackets `()`. `calculator.add` gives you the **function itself**, and `calculator.add(5, 3)` actually **runs** it.

## The `this` Keyword

Inside a method, **`this`** means **"the object I belong to."**

Think of it like saying **"my"**. When your phone says *"**my** battery is 40%"*, it means **its own** battery. 🔋

::js-playground
```js
const phone = {
  brand: "Redmi",
  battery: 40,

  status() {
    return `${this.brand} battery: ${this.battery}%`;
  },

  charge() {
    this.battery = 100;   // changes this object's own property
    return "Fully charged ⚡";
  }
};

console.log(phone.status());   // Redmi battery: 40%
console.log(phone.charge());   // Fully charged ⚡
console.log(phone.status());   // Redmi battery: 100%
```
::

### Real example: a bank account 🏦

::js-playground
```js
const account = {
  holder: "Amit",
  balance: 5000,

  deposit(amount) {
    this.balance += amount;
    return `Deposited ₹${amount}. Balance: ₹${this.balance}`;
  },

  withdraw(amount) {
    if (amount > this.balance) {
      return "❌ Insufficient balance";
    }
    this.balance -= amount;
    return `Withdrew ₹${amount}. Balance: ₹${this.balance}`;
  }
};

console.log(account.deposit(2000));    // Deposited ₹2000. Balance: ₹7000
console.log(account.withdraw(10000));  // ❌ Insufficient balance
console.log(account.withdraw(1500));   // Withdrew ₹1500. Balance: ₹5500
```
::

### ⚠️ Don't use arrow functions as methods

Arrow functions **don't have their own `this`**, so `this` won't point to the object.

::js-playground
```js
const user = {
  userName: "Neha",

  greetArrow: () => `Hi, ${this.userName}`,   // ❌ this is NOT the user
  greet() {
    return `Hi, ${this.userName}`;         // ✅ this is the user
  }
};

console.log(user.greetArrow());   // Hi, undefined
console.log(user.greet());        // Hi, Neha
```
::

> **Rule:** For methods that use `this`, use the **short method syntax** `greet() { }`.

## Useful Built-in Object Methods

JavaScript gives us ready-made tools in the **`Object`** helper.

| Method | What it does |
|--------|-------------|
| `Object.keys(obj)` | Gives an array of **keys** |
| `Object.values(obj)` | Gives an array of **values** |
| `Object.entries(obj)` | Gives an array of **[key, value]** pairs |
| `Object.assign(target, source)` | **Copies** properties into another object |
| `Object.freeze(obj)` | **Locks** the object so it can't be changed |

### keys, values, entries

::js-playground
```js
const menu = { Dosa: 80, Idli: 50, Coffee: 30 };

console.log(Object.keys(menu));     // ["Dosa", "Idli", "Coffee"]
console.log(Object.values(menu));   // [80, 50, 30]

const total = Object.values(menu).reduce((sum, price) => sum + price, 0);
console.log(`Total: ₹${total}`);    // Total: ₹160

for (const [item, price] of Object.entries(menu)) {
  console.log(`${item} → ₹${price}`);
}
```
::

### Copying and merging objects

::js-playground
```js
const defaults = { theme: "light", language: "English" };
const userChoice = { theme: "dark" };

// Using spread (modern ✅)
const settings = { ...defaults, ...userChoice };
console.log(settings);   // { theme: "dark", language: "English" }

// Using Object.assign (same result)
const settings2 = Object.assign({}, defaults, userChoice);
console.log(settings2);  // { theme: "dark", language: "English" }
```
::

If both objects have the same key, the **later one wins**. That's why `theme` became `"dark"`.

### Freezing an object 🧊

`Object.freeze()` makes an object immutable by preventing its existing properties from being **added, removed, or modified**.

Once an object is frozen, its properties cannot be changed directly.

::js-playground
```js
const config = Object.freeze({ gstRate: 18, currency: "₹" });

config.gstRate = 5;        // silently ignored
config.newKey = "test";    // silently ignored

console.log(config);       // { gstRate: 18, currency: "₹" }
```
::

### Real-Life Use Case

Imagine a **configuration object** containing application settings that should never change at runtime.

::js-playground
```js
const config = {
  apiUrl: "https://api.example.com",
  timeout: 5000
};

Object.freeze(config);

config.timeout = 10000;

console.log(config.timeout); // 5000
```
::

Here, freezing config prevents accidental changes to important application settings.

Use `Object.freeze()` for settings that should **never change**.

## Quick Summary Table

| Task | Code |
|------|------|
| Read a property | `obj.name` |
| Write a method | `greet() { return "Hi"; }` |
| Call a method | `obj.greet()` |
| Use own data inside a method | `this.name` |
| Get keys / values / pairs | `Object.keys()`, `Object.values()`, `Object.entries()` |
| Merge objects | `{ ...a, ...b }` |
| Lock an object | `Object.freeze(obj)` |

## Key Takeaways

- **Properties** are what an object **has** (data). **Methods** are what an object **can do** (functions).
- Write methods with the short syntax `name() { }`, and call them with `obj.name()`.
- Inside a method, **`this`** means **the object itself**, like saying "my".
- Avoid **arrow functions** for methods that use `this`.
- Use `Object.keys()`, `Object.values()`, and `Object.entries()` to look inside objects, `{ ...a, ...b }` to merge them, and `Object.freeze()` to lock them.
