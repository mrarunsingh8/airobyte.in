# Object-Based Coding Problems

You've learned how to create objects, read and update properties, write methods, destructure, copy, and use `Object.keys`, `Object.values`, and `Object.entries`. Now it's **practice time!** 💪

Objects are used **everywhere** in real apps: user profiles, shopping carts, orders, settings, and data from servers. Getting comfortable with them is one of the **most useful skills** in JavaScript.

## How to Use This Lesson

For every problem:

1. 📖 **Read** the problem and the example.
2. 🤔 **Think** about the steps on paper first.
3. ⌨️ **Try** your own code in the playground.
4. ✅ **Then** check the solution.

> Getting stuck is normal. The learning happens when you **try first**. 🙌

## Your Object Toolbox 🧰

Most object problems are solved with these few tools:

| Tool | What it does |
|------|-------------|
| `for...in` | Loop through the keys |
| `Object.keys(obj)` | Get an array of keys |
| `Object.values(obj)` | Get an array of values |
| `Object.entries(obj)` | Get `[key, value]` pairs |
| `Object.fromEntries(pairs)` | Turn pairs back into an object |
| `obj[key]` | Read or write a key stored in a variable |
| `key in obj` | Check if a key exists |
| `{ ...obj }` | Make a copy |

# 🟢 Level 1: Easy

## Problem 1: Count the Properties

**Task:** Find how many details a product has.

**Input:** `{ name: "Laptop", brand: "Dell", ram: "16GB", price: 55000 }`
**Output:** `4`

💡 **Idea:** Get all the keys as an array, then check its length.

::js-playground
```js
const product = { name: "Laptop", brand: "Dell", ram: "16GB", price: 55000 };

// Method 1: Using Object.keys
console.log(Object.keys(product).length);   // 4

// Method 2: Using a loop
let count = 0;
for (const key in product) {
  count++;
}
console.log(count);   // 4
```

## Problem 2: Sum of All Values

**Task:** Find the total monthly expenses.

**Input:** `{ rent: 12000, food: 6000, travel: 2000, phone: 500 }`
**Output:** `Total: ₹20500`

💡 **Idea:** Take all the values as an array, then add them up.

::js-playground
```js
const expenses = { rent: 12000, food: 6000, travel: 2000, phone: 500 };

// Method 1: Using a loop
let total = 0;
for (const item in expenses) {
  total += expenses[item];
}
console.log(`Total: ₹${total}`);

// Method 2: Using Object.values + reduce
const total2 = Object.values(expenses).reduce((sum, amount) => sum + amount, 0);
console.log(`Total: ₹${total2}`);
```

## Problem 3: Find the Highest Value

**Task:** Find the subject with the highest marks.

**Input:** `{ Maths: 88, Science: 95, English: 76, Hindi: 82 }`
**Output:** `Top subject: Science (95)`

💡 **Idea:** Keep track of the **best subject so far**. Update it whenever you find higher marks.

::js-playground
```js
const marks = { Maths: 88, Science: 95, English: 76, Hindi: 82 };

let topSubject = "";
let topMarks = -Infinity;

for (const [subject, score] of Object.entries(marks)) {
  if (score > topMarks) {
    topMarks = score;
    topSubject = subject;
  }
}

console.log(`Top subject: ${topSubject} (${topMarks})`);
```

## Problem 4: Check If a Key Exists

**Task:** Check if a user has added a phone number to their profile.

**Input:** `{ name: "Neha", email: "neha@mail.com" }`, key: `"phone"`
**Output:** `Phone not added ❌`

💡 **Idea:** Use the `in` operator or `Object.hasOwn()`. Don't just check the value, because a value like `0` or `""` would look "missing."

::js-playground
```js
const profile = { name: "Neha", email: "neha@mail.com" };

if ("phone" in profile) {
  console.log("Phone added ✅");
} else {
  console.log("Phone not added ❌");
}

console.log(Object.hasOwn(profile, "email"));   // true
```

## Problem 5: Print an Object Nicely

**Task:** Print a restaurant bill from a menu order.

**Input:** `{ "Paneer Tikka": 280, "Butter Naan": 60, "Lassi": 80 }`
**Output:**
```
Paneer Tikka ....... ₹280
Butter Naan ........ ₹60
Lassi .............. ₹80
```

💡 **Idea:** Loop through the pairs. Use `padEnd()` to line up the dots.

::js-playground
```js
const order = { "Paneer Tikka": 280, "Butter Naan": 60, "Lassi": 80 };

for (const [item, price] of Object.entries(order)) {
  console.log(`${(item + " ").padEnd(20, ".")} ₹${price}`);
}
```

# 🟡 Level 2: Medium

## Problem 6: Count Characters in a Word

**Task:** Count how many times each letter appears.

**Input:** `"banana"`
**Output:** `{ b: 1, a: 3, n: 2 }`

💡 **Idea:** Use an object like a **tally sheet** ✍️. For each letter, add 1 to its count.

::js-playground
```js
function countLetters(word) {
  const count = {};

  for (const letter of word) {
    count[letter] = (count[letter] || 0) + 1;
  }

  return count;
}

console.log(countLetters("banana"));     // { b: 1, a: 3, n: 2 }
console.log(countLetters("mississippi"));
```
::

**How `(count[letter] || 0) + 1` works:**
- First time we see `"a"` → `count["a"]` is `undefined` → `undefined || 0` gives `0` → `0 + 1 = 1`
- Next time → `count["a"]` is `1` → `1 + 1 = 2`

## Problem 7: Swap Keys and Values

**Task:** Turn a "state → capital" object into "capital → state".

**Input:** `{ Maharashtra: "Mumbai", Karnataka: "Bengaluru", Bihar: "Patna" }`
**Output:** `{ Mumbai: "Maharashtra", Bengaluru: "Karnataka", Patna: "Bihar" }`

💡 **Idea:** For each pair, make the **value** the new key and the **key** the new value.

::js-playground
```js
const capitals = { Maharashtra: "Mumbai", Karnataka: "Bengaluru", Bihar: "Patna" };

// Method 1: Using a loop
const flipped = {};
for (const [state, capital] of Object.entries(capitals)) {
  flipped[capital] = state;
}
console.log(flipped);

// Method 2: Using entries + fromEntries
const flipped2 = Object.fromEntries(
  Object.entries(capitals).map(([state, capital]) => [capital, state])
);
console.log(flipped2);
```

## Problem 8: Filter an Object

**Task:** Keep only the items that are in stock.

**Input:** `{ Rice: 50, Sugar: 0, Dal: 20, Oil: 0, Salt: 35 }`
**Output:** `{ Rice: 50, Dal: 20, Salt: 35 }`

💡 **Idea:** Objects don't have a `filter()` method, but arrays do! Convert to pairs, filter them, then convert back.

```
Object → entries → filter → fromEntries → Object
```

::js-playground
```js
const stock = { Rice: 50, Sugar: 0, Dal: 20, Oil: 0, Salt: 35 };

const inStock = Object.fromEntries(
  Object.entries(stock).filter(([item, qty]) => qty > 0)
);

console.log(inStock);   // { Rice: 50, Dal: 20, Salt: 35 }

const outOfStock = Object.keys(stock).filter((item) => stock[item] === 0);
console.log("Out of stock:", outOfStock);   // ["Sugar", "Oil"]
```

## Problem 9: Merge Two Objects

**Task:** Combine the default app settings with the user's choices. The user's choices should **win**.

**Input:** defaults `{ theme: "light", language: "English", notifications: true }`, user `{ theme: "dark", language: "Hindi" }`
**Output:** `{ theme: "dark", language: "Hindi", notifications: true }`

💡 **Idea:** Use spread `...`. When the same key appears twice, the **later** one wins.

::js-playground
```js
const defaults = { theme: "light", language: "English", notifications: true };
const userChoice = { theme: "dark", language: "Hindi" };

const settings = { ...defaults, ...userChoice };

console.log(settings);
// { theme: "dark", language: "Hindi", notifications: true }
```

## Problem 10: Group Items by a Property

**Task:** Group students by their city.

**Input:**
```js
[
  { name: "Aarav", city: "Delhi" },
  { name: "Diya", city: "Pune" },
  { name: "Kabir", city: "Delhi" },
  { name: "Meera", city: "Pune" },
  { name: "Rohan", city: "Jaipur" }
]
```
**Output:** `{ Delhi: ["Aarav", "Kabir"], Pune: ["Diya", "Meera"], Jaipur: ["Rohan"] }`

💡 **Idea:** For each student, check if their city already has a list. If not, **create an empty list** first. Then add the name.

::js-playground
```js
const students = [
  { name: "Aarav", city: "Delhi" },
  { name: "Diya", city: "Pune" },
  { name: "Kabir", city: "Delhi" },
  { name: "Meera", city: "Pune" },
  { name: "Rohan", city: "Jaipur" }
];

const byCity = {};

for (const student of students) {
  if (!byCity[student.city]) {
    byCity[student.city] = [];      // create a new group
  }
  byCity[student.city].push(student.name);
}

console.log(byCity);
```

## Problem 11: Shopping Cart Total 🛒

**Task:** Find the total bill of a cart, where each item has a price and a quantity.

**Input:**
```js
[
  { item: "Shoes", price: 1999, qty: 1 },
  { item: "Socks", price: 199, qty: 3 },
  { item: "Cap", price: 499, qty: 2 }
]
```
**Output:** `Total: ₹3594`

💡 **Idea:** For each item, multiply the price by the quantity, then add everything up.

::js-playground
```js
const cart = [
  { item: "Shoes", price: 1999, qty: 1 },
  { item: "Socks", price: 199, qty: 3 },
  { item: "Cap", price: 499, qty: 2 }
];

const total = cart.reduce((sum, product) => sum + product.price * product.qty, 0);

for (const { item, price, qty } of cart) {
  console.log(`${item}: ₹${price} × ${qty} = ₹${price * qty}`);
}
console.log(`Total: ₹${total}`);
```

## Problem 12: Remove Empty Values

**Task:** Clean up a form by removing fields that are empty, `null`, or `undefined`.

**Input:** `{ name: "Ravi", email: "", phone: null, city: "Pune", pincode: undefined, age: 0 }`
**Output:** `{ name: "Ravi", city: "Pune", age: 0 }`

💡 **Idea:** Keep a field only if its value is **not** `""`, `null`, or `undefined`. Be careful: `0` is a real value, so don't remove it!

::js-playground
```js
const form = { name: "Ravi", email: "", phone: null, city: "Pune", pincode: undefined, age: 0 };

const cleaned = Object.fromEntries(
  Object.entries(form).filter(([key, value]) => value !== "" && value != null)
);

console.log(cleaned);   // { name: "Ravi", city: "Pune", age: 0 }
```
::

> `value != null` (with **two** `=`) is a handy shortcut that checks for **both** `null` and `undefined`.

## Problem 13: Check If Two Words Are Anagrams ⭐

**Task:** Two words are **anagrams** if they have the **same letters**, just in a different order.

**Input:** `"listen"` and `"silent"`
**Output:** `true`

💡 **Idea:** Count the letters in both words using objects (like Problem 6). If both counts match, they are anagrams.

::js-playground
```js
function isAnagram(a, b) {
  if (a.length !== b.length) return false;

  const count = {};

  for (const letter of a) {
    count[letter] = (count[letter] || 0) + 1;   // add letters from word 1
  }

  for (const letter of b) {
    if (!count[letter]) return false;            // letter missing or used up
    count[letter]--;                             // remove letters from word 2
  }

  return true;
}

console.log(isAnagram("listen", "silent"));   // true
console.log(isAnagram("hello", "world"));     // false
console.log(isAnagram("aab", "abb"));         // false
```

## Problem 14: First Non-Repeating Character

**Task:** Find the first letter that appears **only once**.

**Input:** `"aabbcdeec"`
**Output:** `"d"`

💡 **Idea:** First, count every letter. Then go through the word again and return the **first** letter whose count is `1`.

::js-playground
```js
function firstUnique(word) {
  const count = {};

  for (const letter of word) {
    count[letter] = (count[letter] || 0) + 1;
  }

  for (const letter of word) {
    if (count[letter] === 1) return letter;
  }

  return null;   // no unique letter
}

console.log(firstUnique("aabbcdeec"));   // d
console.log(firstUnique("javascript"));  // j
console.log(firstUnique("aabb"));        // null
```
::

## Problem 15: Deep Compare Two Objects

**Task:** Check if two objects have **exactly the same** keys and values, even nested ones.

💡 **Why not `===`?** Because `===` checks if they are the **same object in memory**, not whether their contents are equal.

::js-playground
```js
const a = { name: "Amit" };
const b = { name: "Amit" };

console.log(a === b);   // false 😮 different objects, even with the same content
```
::

💡 **Idea:**
1. If both values are **not objects**, compare them with `===`.
2. If they have a **different number of keys**, they are not equal.
3. Otherwise, compare **each key's value** using the same function (recursion).

::js-playground
```js
function isEqual(x, y) {
  // Not objects (or null)? Compare directly
  if (typeof x !== "object" || typeof y !== "object" || x === null || y === null) {
    return x === y;
  }

  const keysX = Object.keys(x);
  const keysY = Object.keys(y);

  if (keysX.length !== keysY.length) return false;

  for (const key of keysX) {
    if (!isEqual(x[key], y[key])) return false;
  }

  return true;
}

const user1 = { name: "Amit", address: { city: "Pune" }, hobbies: ["Cricket"] };
const user2 = { name: "Amit", address: { city: "Pune" }, hobbies: ["Cricket"] };
const user3 = { name: "Amit", address: { city: "Delhi" }, hobbies: ["Cricket"] };

console.log(isEqual(user1, user2));   // true
console.log(isEqual(user1, user3));   // false
```

## Problem 16: Get a Nested Value from a Path

**Task:** Read a deep value using a path string like `"customer.address.city"`.

**Input:** order object, path: `"customer.address.city"`
**Output:** `"Jaipur"`

💡 **Idea:** Split the path by `"."`, then go one step deeper for each part. If any step is missing, return `undefined` instead of crashing.

::js-playground
```js
function getValue(obj, path) {
  let current = obj;

  for (const key of path.split(".")) {
    current = current?.[key];   // go one level deeper, safely
  }

  return current;
}

const order = {
  id: 501,
  customer: {
    name: "Amit",
    address: { city: "Jaipur", pincode: 302001 }
  }
};

console.log(getValue(order, "customer.address.city"));   // Jaipur
console.log(getValue(order, "customer.name"));           // Amit
console.log(getValue(order, "customer.phone.mobile"));   // undefined (no crash)
```

## Problem 17: Flatten a Nested Object

**Task:** Turn a nested object into a flat one, with dotted keys.

**Input:** `{ name: "Amit", address: { city: "Pune", pin: { code: 411001 } } }`
**Output:** `{ name: "Amit", "address.city": "Pune", "address.pin.code": 411001 }`

💡 **Idea:** Go through each key. If the value is an object, **flatten it too** (recursion), adding the parent key in front with a dot.

::js-playground
```js
function flattenObject(obj, prefix = "", result = {}) {
  for (const [key, value] of Object.entries(obj)) {
    const newKey = prefix ? `${prefix}.${key}` : key;

    if (typeof value === "object" && value !== null && !Array.isArray(value)) {
      flattenObject(value, newKey, result);   // go deeper
    } else {
      result[newKey] = value;                 // save the value
    }
  }
  return result;
}

const user = {
  name: "Amit",
  address: { city: "Pune", pin: { code: 411001 } }
};

console.log(flattenObject(user));
// { name: "Amit", "address.city": "Pune", "address.pin.code": 411001 }
```

## Problem 18: Most Frequent Item

**Task:** Find the most ordered dish in a restaurant. 🍽️

**Input:** `["Biryani", "Dosa", "Biryani", "Paneer", "Dosa", "Biryani"]`
**Output:** `Most ordered: Biryani (3 times)`

💡 **Idea:** Count every dish (like Problem 6), then find the one with the highest count (like Problem 3). Two easy problems combined into one! 🧩

::js-playground
```js
const orders = ["Biryani", "Dosa", "Biryani", "Paneer", "Dosa", "Biryani"];

// Step 1: count
const count = {};
for (const dish of orders) {
  count[dish] = (count[dish] || 0) + 1;
}

// Step 2: find the highest
let topDish = "";
let topCount = 0;

for (const [dish, times] of Object.entries(count)) {
  if (times > topCount) {
    topDish = dish;
    topCount = times;
  }
}

console.log(count);
console.log(`Most ordered: ${topDish} (${topCount} times)`);
```

## Common Patterns You Just Learned

| Pattern | Used in | Idea |
|---------|---------|------|
| **Tally object** | Count letters, anagram, most frequent | `count[x] = (count[x] \|\| 0) + 1` |
| **Track the best** | Highest value, most frequent | Remember the best key and value so far |
| **entries → array method → fromEntries** | Filter, swap, clean | Use array tools on objects |
| **Group into lists** | Group by city | Create an empty list first, then push |
| **Spread merge** | Settings | `{ ...defaults, ...choices }` |
| **Recursion** | Deep compare, flatten | Handle a nested object with the same function |
| **Safe path walking** | Get nested value | Use `?.` at every step |

## Tips for Solving Object Problems

- ✅ Remember: **objects don't have** `map`, `filter`, or `reduce`. Use **`Object.entries()`** first, then convert back with **`Object.fromEntries()`**.
- ✅ Use **bracket notation** `obj[key]` when the key is in a variable.
- ✅ Use **`in`** or **`Object.hasOwn()`** to check if a key exists, not the value.
- ✅ Test with **edge cases**: an empty object `{}`, missing keys, `0`, `""`, and `null` values.
- ✅ Use `console.log()` inside your loops to see what's happening at each step.

## Key Takeaways

- Most object problems use a few **patterns**: tally objects, tracking the best value, grouping, merging, and converting with `entries`/`fromEntries`.
- A **tally object** `count[x] = (count[x] || 0) + 1` solves counting, anagram, and most-frequent problems.
- To **filter or transform** an object, go **object → entries → array method → fromEntries → object**.
- `===` compares objects by **reference**, not content, so write a **deep compare** to check if contents match.
- Big problems are often **two small problems combined**, like counting first and then finding the highest. 🧩
