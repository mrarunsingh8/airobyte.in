# Strings in JavaScript

Every app you use is full of **text**: your name on Instagram, a WhatsApp message, an OTP, a product name on Flipkart, a train name on IRCTC. 📱

In JavaScript, text is stored as a **string**.

::js-playground
```js
const name = "Priya";
const message = 'Your OTP is 4321';
const city = `Bengaluru`;

console.log(name, message, city);
```
::

---

## What Is a String?

> 📝 **Definition:** A **string** is a **sequence of characters** (letters, numbers, spaces, symbols, or emojis) used to store **text**. It is a **primitive data type** in JavaScript.

Think of a string like a **garland of beads** 📿. Each bead is one character, and the beads are kept **in order** on one thread.

```
"HELLO"
 H  E  L  L  O
 0  1  2  3  4   ← each character has a position (index)
```

### Three ways to write a string

| Quotes | Example | Notes |
|--------|---------|-------|
| Double quotes `" "` | `"Hello"` | Very common |
| Single quotes `' '` | `'Hello'` | Same as double quotes |
| Backticks `` ` ` `` | `` `Hello` `` | **Template literals**, with extra powers ✨ |

### Useful basics

::js-playground
```js
const word = "NAMASTE";

console.log(word.length);   // 7 (number of characters)
console.log(word[0]);       // N (first character)
console.log(word.at(-1));   // E (last character)
console.log(word[10]);      // undefined (no character here)
```
::

### Quotes inside a string

::js-playground
```js
const a = "It's a sunny day";             // single quote inside double quotes
const b = 'She said "Namaste"';           // double quotes inside single quotes
const c = 'It\'s fine';                   // escape with a backslash \
const d = `She said "It's okay"`;         // backticks handle both easily ✅

console.log(a);
console.log(b);
console.log(c);
console.log(d);
```
::

### Special characters (escape sequences)

| Code | Meaning |
|------|---------|
| `\n` | New line |
| `\t` | Tab space |
| `\\` | A backslash |
| `\'` / `\"` | A quote |

::js-playground
```js
console.log("Name:\tPriya\nCity:\tPune");
```
::

# Part 1: Template Literals

## The Old Way: Joining with `+`

Imagine printing a **train ticket** 🎫:

::js-playground
```js
const passenger = "Rohan";
const train = "Rajdhani";
const seat = "B2-34";

const ticket = "Passenger: " + passenger + ", Train: " + train + ", Seat: " + seat;

console.log(ticket);
```
::

It works, but all those `+` signs and quotes are **messy** and easy to get wrong. 😵

## The Better Way: Template Literals ✨

> 📝 **Definition:** **Template literals** are strings written with **backticks `` ` ` ``**. They let you put **variables and expressions** directly inside the text using **`${ }`**, and they can span **multiple lines**.

::js-playground
```js
const passenger = "Rohan";
const train = "Rajdhani";
const seat = "B2-34";

const ticket = `Passenger: ${passenger}, Train: ${train}, Seat: ${seat}`;

console.log(ticket);
```
::

Much cleaner! Think of it like a **fill-in-the-blanks** form 📝: the `${ }` are the blanks, and JavaScript fills them in.

## 1. Putting Expressions Inside `${ }`

You can put **any expression** inside `${ }`: maths, function calls, and even ternary operators.

::js-playground
```js
const price = 499;
const qty = 3;

console.log(`Total: ₹${price * qty}`);                        // maths
console.log(`Name: ${"priya".toUpperCase()}`);                // method call
console.log(`Status: ${qty > 0 ? "In cart 🛒" : "Empty"}`);   // ternary
console.log(`Items: ${qty} ${qty === 1 ? "item" : "items"}`); // singular or plural
```
::

## 2. Multi-Line Strings

With normal quotes, you need `\n` for new lines. With backticks, just **press Enter**.

::js-playground
```js
const name = "Kavya";
const amount = 1250;

const sms = `Dear ${name},
Your payment of ₹${amount} was successful. ✅
Thank you for shopping with us!`;

console.log(sms);
```
::

## 3. Building HTML Text (Common in Real Apps)

::js-playground
```js
const product = { name: "Wireless Earbuds", price: 1499, rating: 4.3 };

const card = `
<div class="card">
  <h2>${product.name}</h2>
  <p>Price: ₹${product.price}</p>
  <p>Rating: ${product.rating} ⭐</p>
</div>`;

console.log(card);
```
::

## 4. Tagged Templates (Advanced, Just a Peek 👀)

A **tag** is a function placed before a template literal. It gets the text parts and the values separately, so it can **process** them.

::js-playground
```js
function highlight(strings, ...values) {
  return strings.reduce((result, text, i) => {
    const value = i < values.length ? `**${values[i]}**` : "";
    return result + text + value;
  }, "");
}

const item = "Biryani";
const price = 250;

console.log(highlight`Your ${item} costs ₹${price}`);
// Your **Biryani** costs ₹**250**
```
::

> As a beginner, you won't write tags often. But libraries use them a lot, for example to write CSS or SQL safely.

### `+` vs template literals

| Point | `+` joining | Template literal |
|-------|-------------|------------------|
| Readability | Messy with many parts | Clean ✅ |
| Expressions | Need extra brackets | Put inside `${ }` |
| Multi-line | Needs `\n` | Just press Enter |
| Quotes inside | Need escaping | No escaping needed |

# Part 2: Common String Methods

Strings come with many **built-in methods**, which are ready-made tools for working with text. 🧰

> ⚠️ **Important:** String methods **never change** the original string. They always **return a new string**. (You'll see why in Part 3!)

## Changing Case

::js-playground
```js
const city = "Mumbai";

console.log(city.toUpperCase());   // MUMBAI
console.log(city.toLowerCase());   // mumbai
```
::

**Real use:** comparing text without worrying about capital letters.

::js-playground
```js
const input = "DeLhI";

console.log(input.toLowerCase() === "delhi");   // true ✅
```
::

## Removing Extra Spaces: `trim()`

Users often type extra spaces by mistake. `trim()` removes spaces from **both ends**.

::js-playground
```js
const email = "   priya@mail.com   ";

console.log(`[${email.trim()}]`);        // [priya@mail.com]
console.log(`[${email.trimStart()}]`);   // [priya@mail.com   ]
console.log(`[${email.trimEnd()}]`);     // [   priya@mail.com]
```
::

## Searching Inside a String

| Method | Returns | Example |
|--------|---------|---------|
| `includes(text)` | `true` / `false` | Does it contain this? |
| `startsWith(text)` | `true` / `false` | Does it start with this? |
| `endsWith(text)` | `true` / `false` | Does it end with this? |
| `indexOf(text)` | Position, or `-1` | Where is it first found? |
| `lastIndexOf(text)` | Position, or `-1` | Where is it last found? |

::js-playground
```js
const message = "Your order from Swiggy has been delivered";

console.log(message.includes("delivered"));   // true
console.log(message.startsWith("Your"));      // true
console.log(message.endsWith("Zomato"));      // false
console.log(message.indexOf("order"));        // 5
console.log(message.indexOf("pizza"));        // -1 (not found)
```
::

**Real example: checking a phone number and email**

::js-playground
```js
const phone = "+91 98765 43210";
const email = "rohan@gmail.com";

console.log(phone.startsWith("+91") ? "Indian number 🇮🇳" : "Other country");
console.log(email.includes("@") && email.endsWith(".com") ? "Looks valid ✅" : "Invalid ❌");
```
::

## Getting Part of a String: `slice()`

`slice(start, end)` cuts out a piece. The `end` index is **not included** (just like arrays).

::js-playground
```js
const word = "JavaScript";

console.log(word.slice(0, 4));   // Java
console.log(word.slice(4));      // Script (from index 4 to the end)
console.log(word.slice(-6));     // Script (last 6 characters)
```
::

**Real example: hiding a card number 💳**

::js-playground
```js
const cardNumber = "4539148803436467";

const masked = "**** **** **** " + cardNumber.slice(-4);

console.log(masked);   // **** **** **** 6467
```
::

> `substring(start, end)` works almost the same as `slice()`, but it **doesn't support negative** numbers. Prefer `slice()`.

## Replacing Text

::js-playground
```js
const text = "I like tea. Tea is great. tea time!";

console.log(text.replace("tea", "coffee"));     // replaces only the FIRST match
console.log(text.replaceAll("tea", "coffee"));  // replaces ALL matches
```
::

> Both methods are **case-sensitive**: `"Tea"` and `"tea"` are different.

## Splitting and Joining

`split()` breaks a string into an **array**. `join()` (an array method) puts the pieces back together.

::js-playground
```js
const fruits = "Mango,Banana,Apple";
console.log(fruits.split(","));        // ["Mango", "Banana", "Apple"]

const sentence = "I love JavaScript";
console.log(sentence.split(" "));      // ["I", "love", "JavaScript"]

const word = "HELLO";
console.log(word.split(""));           // ["H", "E", "L", "L", "O"]

const words = ["Good", "Morning", "India"];
console.log(words.join(" "));          // Good Morning India
console.log(words.join("-"));          // Good-Morning-India
```
::

## Repeating and Padding

::js-playground
```js
console.log("Ha".repeat(3));           // HaHaHa
console.log("-".repeat(20));           // --------------------

// padStart: add characters at the START until the length is reached
console.log("7".padStart(3, "0"));     // 007
console.log("42".padStart(5, "*"));    // ***42

// padEnd: add characters at the END
console.log("Tea".padEnd(10, ".") + "₹20");   // Tea.......₹20
```
::

**Real example: order and roll numbers**

::js-playground
```js
for (let i = 1; i <= 3; i++) {
  console.log(`Roll No: ${String(i).padStart(3, "0")}`);
}
// Roll No: 001, Roll No: 002, Roll No: 003
```
::

## Reading Characters

::js-playground
```js
const word = "India";

console.log(word.charAt(0));       // I
console.log(word.at(-1));          // a (last character)
console.log(word.charCodeAt(0));   // 73 (the character's code number)
```
::

## Chaining Methods 🔗

Because each method returns a **new string**, you can **connect** them one after another.

::js-playground
```js
const input = "   hello WORLD   ";

const clean = input
  .trim()              // "hello WORLD"
  .toLowerCase()       // "hello world"
  .replace("world", "India");   // "hello India"

console.log(clean);   // hello India
```
::

## Quick Methods Table

| Method | What it does | Example | Result |
|--------|-------------|---------|--------|
| `length` | Counts characters | `"Hi".length` | `2` |
| `toUpperCase()` | All capitals | `"hi".toUpperCase()` | `"HI"` |
| `toLowerCase()` | All small letters | `"HI".toLowerCase()` | `"hi"` |
| `trim()` | Removes outer spaces | `" hi ".trim()` | `"hi"` |
| `includes()` | Contains? | `"hello".includes("ell")` | `true` |
| `startsWith()` | Starts with? | `"hello".startsWith("he")` | `true` |
| `endsWith()` | Ends with? | `"hello".endsWith("lo")` | `true` |
| `indexOf()` | Position of text | `"hello".indexOf("l")` | `2` |
| `slice()` | Cuts a part | `"hello".slice(1, 3)` | `"el"` |
| `replace()` | Replaces the first match | `"aa".replace("a", "b")` | `"ba"` |
| `replaceAll()` | Replaces all matches | `"aa".replaceAll("a", "b")` | `"bb"` |
| `split()` | String → array | `"a,b".split(",")` | `["a", "b"]` |
| `repeat()` | Repeats text | `"ab".repeat(2)` | `"abab"` |
| `padStart()` | Pads at the start | `"5".padStart(2, "0")` | `"05"` |
| `at()` | Character at a position | `"hello".at(-1)` | `"o"` |

# Part 3: String Immutability

> 📝 **Definition:** **Immutable** means **"cannot be changed."** In JavaScript, strings are **immutable**: once a string is created, its characters **can never be changed**. Every string method gives you a **new string** instead.

Think of a string like a **printed newspaper** 📰. You can't change the letters printed on it. If you want different text, you have to **print a new newspaper**.

### You can't change a character directly

::js-playground
```js
let word = "Hello";

word[0] = "J";   // try to change "H" to "J"

console.log(word);   // Hello 😮 (nothing changed!)
```
::

JavaScript simply **ignores** this. (In strict mode, it even throws an error.)

### Methods don't change the original

::js-playground
```js
const name = "priya";

name.toUpperCase();        // creates "PRIYA"... but we didn't save it!
console.log(name);         // priya (original is unchanged)

const upper = name.toUpperCase();   // ✅ save the NEW string
console.log(upper);        // PRIYA
```
::

> ⚠️ **Most common beginner mistake:** calling a string method and **forgetting to save the result**.

### So how do we "change" a string?

We **create a new string** and store it in the variable. The **variable** can point to a new string, but the **old string itself** never changes.

::js-playground
```js
let word = "Hello";

word = "J" + word.slice(1);   // build a NEW string, then point `word` to it

console.log(word);   // Jello ✅
```
::

It's like writing a **new name tag** 🏷️ and sticking it on the box. The old tag isn't edited; it's **replaced**.

### Variable vs value: `let` vs `const`

| | Can you give the variable a new string? | Can you change the characters? |
|---|---|---|
| `let str` | ✅ Yes | ❌ No (strings are immutable) |
| `const str` | ❌ No | ❌ No (strings are immutable) |

### Strings vs arrays

Arrays **can** be changed in place. Strings **cannot**. That's a big difference!

::js-playground
```js
const letters = ["H", "e", "l", "l", "o"];
letters[0] = "J";
console.log(letters.join(""));   // Jello (array changed ✅)

const text = "Hello";
const changed = text.split("");  // turn it into an array
changed[0] = "J";                // change the array
console.log(changed.join(""));   // Jello (a NEW string)
console.log(text);               // Hello (original is safe)
```
::

**Tip:** If you need to change many characters, **split** the string into an array, change the array, then **join** it back.

### Why are strings immutable? 🤔

- **Safety:** A string you pass to a function can never be changed by accident.
- **Speed:** JavaScript can safely share and reuse the same string in memory.
- **Predictability:** The same string always has the same value.

### ⚠️ Building strings in big loops

Every `+=` creates a **new string**. For a few items, that's fine. For thousands of pieces, collecting them in an **array** and joining once is cleaner.

::js-playground
```js
// ✅ Fine for small loops
let stars = "";
for (let i = 0; i < 5; i++) {
  stars += "⭐";
}
console.log(stars);

// ✅ Clean for building bigger text
const lines = [];
for (let i = 1; i <= 3; i++) {
  lines.push(`Line ${i}`);
}
console.log(lines.join("\n"));
```

## 🟢 Problem 1: Reverse a String

**Input:** `"India"`
**Output:** `"aidnI"`

💡 **Idea:** Split into an array of characters, reverse the array, and join it back.

::js-playground
```js
const word = "India";

// Method 1: split → reverse → join
console.log(word.split("").reverse().join(""));   // aidnI

// Method 2: using a loop
let reversed = "";
for (const char of word) {
  reversed = char + reversed;   // add each character at the FRONT
}
console.log(reversed);   // aidnI
```

## 🟢 Problem 2: Count Vowels

**Input:** `"Bengaluru"`
**Output:** `4`

💡 **Idea:** Go through each character, and count it if it's one of `a, e, i, o, u`.

::js-playground
```js
function countVowels(text) {
  let count = 0;
  for (const char of text.toLowerCase()) {
    if ("aeiou".includes(char)) count++;
  }
  return count;
}

console.log(countVowels("Bengaluru"));    // 4
console.log(countVowels("JavaScript"));   // 3
```
::

## 🟢 Problem 3: Capitalise the First Letter of Each Word

**Input:** `"welcome to namma bengaluru"`
**Output:** `"Welcome To Namma Bengaluru"`

💡 **Idea:** Split into words, capitalise the first letter of each word, then join them back.

::js-playground
```js
function titleCase(sentence) {
  return sentence
    .split(" ")
    .map((word) => word[0].toUpperCase() + word.slice(1).toLowerCase())
    .join(" ");
}

console.log(titleCase("welcome to namma bengaluru"));
```
::

## 🟢 Problem 4: Check for a Palindrome

A **palindrome** reads the **same forwards and backwards**, like `"madam"` or `"racecar"`. 🔁

**Input:** `"Madam"`
**Output:** `true`

💡 **Idea:** Clean the text (lowercase, remove spaces and symbols), then compare it with its reverse.

::js-playground
```js
function isPalindrome(text) {
  const clean = text.toLowerCase().replace(/[^a-z0-9]/g, "");
  return clean === clean.split("").reverse().join("");
}

console.log(isPalindrome("Madam"));                            // true
console.log(isPalindrome("A man, a plan, a canal: Panama"));   // true
console.log(isPalindrome("Hello"));                            // false
```
::

> `/[^a-z0-9]/g` is a **regular expression** that means *"any character that is NOT a letter or number."* Replacing it with `""` removes spaces and symbols.

## 🟡 Problem 5: Count Words

**Input:** `"  I   love   learning JavaScript  "`
**Output:** `4`

💡 **Idea:** Trim the ends, then split on **one or more spaces**, so extra spaces don't create empty "words."

::js-playground
```js
function countWords(text) {
  const trimmed = text.trim();
  if (trimmed === "") return 0;
  return trimmed.split(/\s+/).length;
}

console.log(countWords("  I   love   learning JavaScript  "));   // 4
console.log(countWords("   "));                                  // 0
```

## 🟡 Problem 6: Find the Longest Word

**Input:** `"I live in Thiruvananthapuram"`
**Output:** `"Thiruvananthapuram"`

💡 **Idea:** Split into words, then keep track of the longest one.

::js-playground
```js
function longestWord(sentence) {
  let longest = "";
  for (const word of sentence.split(" ")) {
    if (word.length > longest.length) {
      longest = word;
    }
  }
  return longest;
}

console.log(longestWord("I live in Thiruvananthapuram"));   // Thiruvananthapuram
```

## 🟡 Problem 9: Check if Two Words Are Anagrams

**Anagrams** have the **same letters** in a different order, like `"listen"` and `"silent"`.

💡 **Idea:** Sort the letters of both words. If the sorted versions match, they are anagrams.

::js-playground
```js
function isAnagram(a, b) {
  const sortLetters = (s) => s.toLowerCase().split("").sort().join("");
  return sortLetters(a) === sortLetters(b);
}

console.log(isAnagram("listen", "silent"));   // true
console.log(isAnagram("Earth", "Heart"));     // true
console.log(isAnagram("hello", "world"));     // false
```

## 🔴 Problem 10: Compress a String

**Input:** `"aaabbcddd"`
**Output:** `"a3b2c1d3"`

💡 **Idea:** Walk through the string, counting how many times the **same character repeats in a row**. When the character changes, save the character and its count.

::js-playground
```js
function compress(text) {
  let result = "";
  let count = 1;

  for (let i = 0; i < text.length; i++) {
    if (text[i] === text[i + 1]) {
      count++;
    } else {
      result += text[i] + count;
      count = 1;
    }
  }

  return result;
}

console.log(compress("aaabbcddd"));   // a3b2c1d3
console.log(compress("abc"));         // a1b1c1
```
::

## 🔴 Problem 11: First Non-Repeating Character

**Input:** `"aabbcdeec"`
**Output:** `"d"`

💡 **Idea:** Count all characters first. Then find the **first** one whose count is `1`.

::js-playground
```js
function firstUnique(text) {
  const count = {};
  for (const char of text) {
    count[char] = (count[char] || 0) + 1;
  }
  for (const char of text) {
    if (count[char] === 1) return char;
  }
  return null;
}

console.log(firstUnique("aabbcdeec"));   // d
console.log(firstUnique("aabb"));        // null
```
::

## 🔴 Problem 12: Convert to camelCase

**Input:** `"total-cart-price"` or `"total cart price"`
**Output:** `"totalCartPrice"`

💡 **Idea:** Split on spaces, `-`, or `_`. Keep the first word in lowercase, and capitalise the first letter of every other word.

::js-playground
```js
function toCamelCase(text) {
  return text
    .toLowerCase()
    .split(/[\s\-_]+/)
    .map((word, i) => (i === 0 ? word : word[0].toUpperCase() + word.slice(1)))
    .join("");
}

console.log(toCamelCase("total-cart-price"));   // totalCartPrice
console.log(toCamelCase("User first name"));    // userFirstName
console.log(toCamelCase("is_logged_in"));       // isLoggedIn
```

## Common Mistakes to Avoid

| Mistake | Problem | Fix |
|---------|---------|-----|
| `str.toUpperCase();` without saving | The original doesn't change | `str = str.toUpperCase();` |
| `str[0] = "X"` | Silently ignored (strings are immutable) | Build a new string: `"X" + str.slice(1)` |
| Using `'` quotes around `'It's'` | ❌ SyntaxError | Use `"It's"` or backticks |
| Writing `"${name}"` with normal quotes | Prints `${name}` literally | Use backticks: `` `${name}` `` |
| Expecting `replace()` to change all matches | Only the first changes | Use `replaceAll()` |
| Comparing `"Delhi" === "delhi"` | `false` (case-sensitive) | Compare with `.toLowerCase()` |
| `"5" + 5` | `"55"` (text joining) | Convert first: `Number("5") + 5` |

| String → array | `str.split(" ")` |
| Array → string | `arr.join(" ")` |
| Reverse | `str.split("").reverse().join("")` |
| Pad with zeros | `str.padStart(3, "0")` |

## Key Takeaways

- A **string** is a sequence of characters used to store **text**. Write it with `" "`, `' '`, or backticks `` ` ` ``.
- **Template literals** (backticks) let you insert values with **`${ }`** and write **multi-line** text easily.
- Strings have many helpful **methods**, like `trim`, `includes`, `slice`, `replaceAll`, `split`, and `padStart`, and you can **chain** them together.
- Strings are **immutable**: their characters can never change. Every method returns a **new string**, so always **save the result**.
- Most string problems use a few tricks: **split → change → join**, **tally objects** for counting, and **Sets** for unique characters.
