# What is JavaScript?

> **JavaScript is a high-level programming language that is mainly used to create interactive web pages and web applications.**

In simple words JavaScript is the programming language that turns static web pages into interactive, living applications.

Think of HTML as the skeleton of a website, CSS as the styling, and JavaScript as the brain that responds to user actions.

## A Movie Ticket Web Application: Why JavaScript Matters

Anita owns a small cinema hall in Jaipur. Her initial Web Application was like a digital poster: it displayed movie titles and timings, but customers could only read it—they couldn't do anything.

To allow users to select seats, calculate prices in real-time, and make online payments, Anita added JavaScript.

## Understanding the Definition, Step by Step

**High-level language**
This means JavaScript is written in easy, English-like words. You don't need to worry about how the computer works inside. You simply tell it what to do.

**Interactive web pages**
Without JavaScript, a page just sits there. With JavaScript, it reacts. When a customer selects 4 tickets, the total price updates immediately.

**Dynamic elements**
"Dynamic" means things that change. JavaScript can show "Housefull!" only when all the seats are booked. The page changes based on the situation.

**Handle events**
An event is anything the user does, like clicking a button or selecting a seat. JavaScript listens for these events and responds. A customer clicks **Book Now**, and JavaScript confirms the booking.

**Manipulate the DOM**
The DOM is the structure of the web page, which the browser keeps in memory. "Manipulate" simply means change. So JavaScript can mark a seat as booked, show messages, or hide sold-out shows without reloading the page.

**Interact with APIs**
An API is a way for two programs to talk. Anita's website can use a payment API to accept UPI payments, or an SMS API to send the ticket to the customer's phone.

## Client-Side and Server-Side

JavaScript is **versatile**, which means it can work in many places.

- **Client-side:** Runs directly on the user's phone or laptop. It delivers instant visual updates, like form validation or live seat calculations.
- **Server-side:** Runs on the backend cinema database (using Node.js). It handles secure database updates, saving bookings, and verifying transactions.

So one language handles both the ticket counter and the back office!

## Your First JavaScript Code

Here is a small example that calculates the ticket price:
::js-playground
```js [js]
let ticketPrice = 150;
let tickets = 4;

let total = ticketPrice * tickets;

console.log("Total amount: ₹" + total);
```
::

**Output:**

::code-group
``` [Output]
Total amount: ₹600
```
::

We stored the ticket price and the number of tickets, multiplied them, and printed the result. Simple!

## Key Takeaways

- JavaScript is a high-level language, so it is easy to read and write.
- It makes web pages interactive and dynamic.
- It handles user events, changes page content through the DOM, and talks to other services using APIs.
- It works on both the client-side (browser) and the server-side.
- Even a few lines of JavaScript can do useful work.
