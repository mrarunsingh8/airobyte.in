# The History of JavaScript

Today, JavaScript runs on almost every website you open. But how did it all start? Let us go back in time and see.

## The Web Before JavaScript

In the early 1990s, the internet was very new. Websites were like **digital brochures**. You could read text and see pictures, but that was all.

There was no way to click a button and get an instant reply. No pop-up messages, no moving elements, nothing interactive. The web was quiet and still.

People wanted websites that could **respond** to them. Someone had to make that happen.

## The Man Behind JavaScript

In 1995, a programmer named **Brendan Eich** was working at a company called **Netscape**. Netscape made one of the most popular web browsers of that time, **Netscape Navigator**.

Brendan was given one important job: add a simple language to the browser that could make web pages interactive.

He worked very fast. He built the first version of the language in only about **10 days**!

## One Language, Three Names

The new language changed its name more than once:

1. **Mocha:** This was the first name, given during development.
2. **LiveScript:** Soon after, it was renamed LiveScript.
3. **JavaScript:** Finally, Netscape and **Sun Microsystems** (the company behind Java) chose the name *JavaScript*.

Why "JavaScript"? At that time, **Java** was a very famous language. Using a similar name helped the new language get attention.

But remember one important point:

> **Java and JavaScript are not the same.** They are two completely different languages with a similar name, like *car* and *carpet*!

## Why JavaScript Was Built

**Client-Side Validation:** Before JavaScript, simple tasks—like checking whether an email address field contained an @ symbol—required sending data across slow dial-up connections to a server and reloading the entire page.

**Glue for the Web:** While Java was meant for heavy enterprise components, JavaScript was designed as an approachable, easy-to-use scripting language to make HTML elements interactive.

## What Early JavaScript Could Do

The first JavaScript was very simple compared to today. Still, it made a big difference. Websites could now:

- Show **pop-up messages**
- Do **small animations**
- **Respond** when users clicked on things

For the first time, websites felt **alive**.

## Making JavaScript a Standard

Soon, other browsers wanted to use JavaScript too. To make sure it worked the same way everywhere, it needed common rules.

So in **1997**, JavaScript was standardized under the name **ECMAScript**. Even today, new JavaScript features are released as ECMAScript versions, like **ES6** (2015).

## From Small Beginnings to Everywhere

JavaScript started as a small language built in a few days. Today, it powers websites, mobile apps, servers, games, and much more. It began as a tiny tool and grew into one of the most important languages in the world.

## Current Impact

What started as a 10-day prototype designed for simple browser scripts now powers over 98% of all websites, running client-side UIs (React, Vue), server-side backends (Node.js), desktop applications (Electron), and mobile apps (React Native).

## Key Takeaways

- JavaScript was created by **Brendan Eich** at **Netscape** in **1995**.
- Its first version was built in about **10 days**.
- It was first called **Mocha**, then **LiveScript**, and finally **JavaScript**.
- **Java and JavaScript are different languages.** Only the names are similar.
- JavaScript was standardized as **ECMAScript** in 1997, so it works the same across browsers.
