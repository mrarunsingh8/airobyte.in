# Arrays in JavaScript

Imagine your mother gives you a **shopping list**. 📝

```
1. Milk
2. Bread
3. Eggs
4. Tomatoes
```

It is **one piece of paper**, but it holds **many items**, written **in order**.

Now imagine instead she gave you **4 separate chits of paper**, one for each item. You might lose one, mix up the order, or forget how many there were. 😅

In JavaScript, an **array** is like that single shopping list. It keeps many values together, neatly, in **one place**.

---

## What Is an Array?

**An array is a special variable that stores many values in an ordered list.**

::js-playground
```js
const shoppingList = ["Milk", "Bread", "Eggs", "Tomatoes"];

console.log(shoppingList);
```
::

**Key points:**
- The values are written inside **square brackets `[ ]`**.
- Each value is separated by a **comma `,`**.
- Each value inside an array is called an **element** (or item).
- The items stay in the **same order** in which you put them.

---

## Why Use an Array?

Let us say you want to store the marks of 5 students.

### ❌ Without an array

```js
let marks1 = 78;
let marks2 = 85;
let marks3 = 92;
let marks4 = 66;
let marks5 = 74;
```

Now think about these problems:
- What if there are **500 students**? Will you create 500 variables? 😩
- How will you find the **total** or the **highest** marks easily?
- How will you **add** a new student's marks later?

### ✅ With an array

::js-playground
```js
const marks = [78, 85, 92, 66, 74];

let total = 0;
for (const mark of marks) {
  total += mark;
}

console.log("Number of students:", marks.length);
console.log("Total marks:", total);
```
::

One variable, and it works for 5 students or 5,000 students!

### Benefits of arrays

| Benefit | Meaning |
|---------|---------|
| **One name, many values** | No need for `marks1`, `marks2`, `marks3`... |
| **Ordered** | Items stay in the order you added them |
| **Easy to loop** | Go through every item with a loop |
| **Easy to grow or shrink** | Add or remove items any time |
| **Built-in tools** | Methods to sort, search, filter, and more |

## Creating Arrays

### 1. Using square brackets `[ ]` (most common ✅)

::js-playground
```js
const cities = ["Delhi", "Mumbai", "Chennai"];
const prices = [99, 249, 499];
const emptyList = [];

console.log(cities);
console.log(prices);
console.log(emptyList);
```
::

### 2. Using `new Array()`

::js-playground
```js
const fruits = new Array("Apple", "Banana", "Mango");

console.log(fruits);
```
::

> ⚠️ **Be careful:** With a **single number**, `new Array()` behaves differently!

::js-playground
```js
const a = new Array(3);   // creates 3 EMPTY slots
const b = [3];            // creates an array with the number 3

console.log(a);          // [ <3 empty items> ]
console.log(a.length);   // 3
console.log(b);          // [3]
```
::

That's why developers **prefer `[ ]`**. It is shorter and has no surprises.

### 3. Using `Array.from()`

`Array.from()` turns something **list-like** into a real array.

::js-playground
```js
// From a string: each letter becomes an item
const letters = Array.from("INDIA");
console.log(letters);   // ["I", "N", "D", "I", "A"]

// Create numbers from 1 to 5
const numbers = Array.from({ length: 5 }, (_, i) => i + 1);
console.log(numbers);   // [1, 2, 3, 4, 5]
```
::

### 4. Using `Array.of()`

`Array.of()` creates an array from the values you give, even a single number.

::js-playground
```js
const single = Array.of(3);
const many = Array.of(10, 20, 30);

console.log(single);   // [3]
console.log(many);     // [10, 20, 30]
```
::

### Arrays can store any type of value

::js-playground
```js
const student = ["Rahul", 21, true, null, ["Maths", "Science"]];

console.log(student);
```
::

An array can even hold **another array** inside it!

> **Tip:** Even though you *can* mix types, it is better to keep **one kind of value per array** (all names, or all prices). It makes your code easier to understand.

## Accessing Array Items

Every item in an array has a **position number** called an **index**.

⚠️ The index **starts from 0**, not 1!

```
shoppingList = [ "Milk", "Bread", "Eggs", "Tomatoes" ]
index:              0        1        2         3
```

Think of it like **floors in a building** in India 🏢: the first floor you enter is the **Ground floor (0)**, then 1st floor, 2nd floor, and so on.

### Reading an item with `[index]`

::js-playground
```js
const shoppingList = ["Milk", "Bread", "Eggs", "Tomatoes"];

console.log(shoppingList[0]);   // Milk (first item)
console.log(shoppingList[2]);   // Eggs
console.log(shoppingList[3]);   // Tomatoes (last item)
console.log(shoppingList[10]);  // undefined (no item here)
```
::

Asking for an index that doesn't exist gives **`undefined`**, not an error.

### Finding the number of items with `.length`

::js-playground
```js
const colors = ["Red", "Green", "Blue", "Yellow"];

console.log(colors.length);   // 4
```
::

**Remember:** The **last index** is always `length - 1`.

::js-playground
```js
const colors = ["Red", "Green", "Blue", "Yellow"];

const lastColor = colors[colors.length - 1];
console.log(lastColor);   // Yellow
```
::

### An easier way: `.at()`

`.at()` works like `[ ]`, but it also accepts **negative numbers**, which count **from the end**.

::js-playground
```js
const trains = ["Rajdhani", "Shatabdi", "Duronto", "Vande Bharat"];

console.log(trains.at(0));    // Rajdhani (first)
console.log(trains.at(-1));   // Vande Bharat (last)
console.log(trains.at(-2));   // Duronto (second last)
```
::

> `trains[-1]` gives `undefined`. Only `.at(-1)` works for negative positions.

## Updating Array Items

To change an item, use its **index** and give it a new value.

::js-playground
```js
const menu = ["Idli", "Dosa", "Vada"];

menu[1] = "Masala Dosa";

console.log(menu);   // ["Idli", "Masala Dosa", "Vada"]
```
::

### Wait, we used `const`, but the array changed? 🤔

Yes! `const` means you **cannot give the variable a completely new array**. But you **can** change the items **inside** it.

::js-playground
```js
const menu = ["Idli", "Dosa"];

menu[0] = "Upma";          // ✅ allowed: changing an item
console.log(menu);

// menu = ["Poha"];        // ❌ TypeError: Assignment to constant variable
```
::

Think of `const` like a **tiffin box that is glued to your table**. You can change the food inside it, but you can't replace the box itself.

## Looping Through an Array

To do something with **every item**, use a loop.

::js-playground
```js
const friends = ["Anjali", "Karan", "Sameer"];

// Using for...of (easiest)
for (const friend of friends) {
  console.log(`Happy Diwali, ${friend}! 🪔`);
}

// Using a normal for loop (when you need the index)
for (let i = 0; i < friends.length; i++) {
  console.log(`${i + 1}. ${friends[i]}`);
}
```
::

## Checking Items in an Array

### Is an item in the array? `includes()`

::js-playground
```js
const cart = ["Shoes", "Watch", "Bag"];

console.log(cart.includes("Watch"));   // true
console.log(cart.includes("Phone"));   // false
```
::

### Where is the item? `indexOf()`

::js-playground
```js
const cart = ["Shoes", "Watch", "Bag"];

console.log(cart.indexOf("Bag"));     // 2
console.log(cart.indexOf("Phone"));   // -1 (not found)
```
::

### Is this value really an array? `Array.isArray()`

::js-playground
```js
console.log(Array.isArray(["a", "b"]));   // true
console.log(Array.isArray("hello"));      // false
console.log(typeof ["a", "b"]);           // "object" (not helpful!)
```
::

`typeof` says `"object"` for arrays, so always use `Array.isArray()` to check.

## Destructuring Arrays

**Destructuring** means **unpacking** the items of an array into separate variables, in **one line**.

Think of opening your **tiffin box** 🍱 and putting the roti, dal, and sabzi on **separate plates**.

### Without destructuring

::js-playground
```js
const person = ["Priya", 24, "Pune"];

const name = person[0];
const age = person[1];
const city = person[2];

console.log(name, age, city);
```
::

### With destructuring ✨

::js-playground
```js
const person = ["Priya", 24, "Pune"];

const [name, age, city] = person;

console.log(name);   // Priya
console.log(age);    // 24
console.log(city);   // Pune
```
::

The variables are filled **by position**: the first variable gets the first item, the second gets the second, and so on.

### Skipping items

Leave an empty space between commas to **skip** an item.

::js-playground
```js
const medals = ["Gold", "Silver", "Bronze"];

const [first, , third] = medals;

console.log(first);   // Gold
console.log(third);   // Bronze
```
::

### Default values

If an item is **missing**, you can give a **default value**.

::js-playground
```js
const order = ["Pizza"];

const [food, drink = "Water"] = order;

console.log(food);    // Pizza
console.log(drink);   // Water (default used, because there was no second item)
```
::

### Collecting the rest with `...`

The **rest operator `...`** collects all the **remaining items** into a new array.

::js-playground
```js
const queue = ["Amit", "Neha", "Ravi", "Sara", "Tanya"];

const [firstPerson, ...everyoneElse] = queue;

console.log(firstPerson);    // Amit
console.log(everyoneElse);   // ["Neha", "Ravi", "Sara", "Tanya"]
```
::

> The `...rest` part must always come **last**.

### Swapping two values 🔄

Destructuring makes swapping super easy, with no extra variable needed.

::js-playground
```js
let left = "Tea";
let right = "Coffee";

[left, right] = [right, left];

console.log(left);    // Coffee
console.log(right);   // Tea
```
::

### Destructuring in a loop

Very useful with `.entries()`, which gives the **index and the value** together.

::js-playground
```js
const toppers = ["Ananya", "Rohan", "Kavya"];

for (const [index, name] of toppers.entries()) {
  console.log(`Rank ${index + 1}: ${name} 🏆`);
}
```
::

## Copying and Joining Arrays with Spread `...`

The **spread operator `...`** spreads out the items of an array. (It looks the same as rest, but it is used on the **right side**.)

### Joining two arrays

::js-playground
```js
const vegMenu = ["Paneer", "Dal"];
const nonVegMenu = ["Chicken", "Fish"];

const fullMenu = [...vegMenu, ...nonVegMenu];

console.log(fullMenu);   // ["Paneer", "Dal", "Chicken", "Fish"]
```
::

### Making a copy

::js-playground
```js
const original = [1, 2, 3];
const copy = [...original];

copy.push(4);

console.log(original);   // [1, 2, 3] (safe ✅)
console.log(copy);       // [1, 2, 3, 4]
```
::

### ⚠️ Why not just `copy = original`?

::js-playground
```js
const original = [1, 2, 3];
const notACopy = original;   // both names point to the SAME array

notACopy.push(4);

console.log(original);   // [1, 2, 3, 4] 😮 the original changed too!
```
::

Arrays are **shared**, like a **Google Doc** link. If you give the same link to a friend and they edit it, you see the change too. To get your **own copy**, use `[...array]`.

## Common Mistakes to Avoid

| Mistake | Problem | Fix |
|---------|---------|-----|
| Starting the index at `1` | You miss the first item | Indexes start at `0` |
| Using `arr[arr.length]` for the last item | Gives `undefined` | Use `arr[arr.length - 1]` or `arr.at(-1)` |
| Using `arr[-1]` | Gives `undefined` | Use `arr.at(-1)` |
| `new Array(5)` expecting `[5]` | Creates 5 empty slots | Use `[5]` |
| Copying with `b = a` | Both point to the same array | Use `b = [...a]` |
| Checking with `typeof` | Always says `"object"` | Use `Array.isArray()` |

| Task | Code |
|------|------|
| Create an array | `const arr = ["a", "b", "c"];` |
| Read the first item | `arr[0]` |
| Read the last item | `arr.at(-1)` |
| Count the items | `arr.length` |
| Change an item | `arr[1] = "x";` |
| Add to the end | `arr.push("d");` |
| Check if an item exists | `arr.includes("a")` |
| Destructure | `const [first, second] = arr;` |
| Copy | `const copy = [...arr];` |
| Join | `const all = [...arr1, ...arr2];` |

## Key Takeaways

- An **array** stores **many values in one ordered list**, written inside `[ ]`.
- We use arrays to avoid creating **many separate variables**, and to easily **loop, add, remove, and search** items.
- Items are accessed by their **index**, which **starts from 0**. Use `.length` to count items and `.at(-1)` for the last item.
- **Destructuring** unpacks items into variables: `const [a, b] = arr`. Use `...rest` to collect the remaining items.
- Use the **spread operator** `[...arr]` to **copy** or **join** arrays safely.
