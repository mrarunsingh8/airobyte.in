# Array in JS


::js-playground
```js
const fruits = ['apple', 'banana', 'mango']

console.log(fruits[0])
console.log(fruits.length)

fruits.push('orange')
console.log(fruits)
```
```ts
const fruits: string[] = ['apple', 'banana', 'mango']

console.log(fruits[0])
console.log(fruits.length)

fruits.push('orange')
console.log(fruits)
```
::

An array is a special variable that stores multiple values in a single place. The values are kept **in order**, and each value can be accessed using its index.


::code-group
```js [main.js]
const subjects = ["Maths", "Science", "English"];

console.log(subjects[0]);       // Maths
console.log(subjects.length);   // 3
```
``` [Preview]
Maths
3
```
::

Arrays are useful when you have a group of related values, such as subjects, names, prices, or scores. Instead of creating a separate variable for every value, you can keep them together in one array.

You can also add, remove, and update items:

```js
const fruits = ["Apple", "Banana"];

fruits.push("Mango");        // Add an item at the end
fruits[0] = "Orange";        // Update the first item
fruits.pop();                // Remove the last item

console.log(fruits);         // ["Orange", "Banana"]
```

**Key points:**
- Written inside square brackets `[ ]`.
- Each item has a position number called an **index**.
- **Counting starts from 0**, not 1! So `subjects[0]` is the first item.
- Can store any type of values.
- Like a **shopping list**: items written one after another.
