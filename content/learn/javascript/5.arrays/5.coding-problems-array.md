# Array-Based Coding Problems

You have learned a lot about arrays: creating them, looping through them, and using methods like `map`, `filter`, `reduce`, and `sort`. Now it's **practice time!** 💪

Learning to code is like **learning to ride a bicycle** 🚲. Reading about it helps a little, but you only get better by actually **riding**. The same is true for coding problems.

## How to Use This Lesson

For every problem:

1. 📖 **Read** the problem and the example carefully.
2. 🤔 **Think** about how you would solve it **on paper** first.
3. ⌨️ **Try** writing your own code in the playground.
4. ✅ **Then** check the solution and the explanation.

> Don't worry if you can't solve a problem on the first try. Even experienced developers get stuck. What matters is that you **try first**. 🙌

## A Simple Plan for Solving Any Problem

| Step | Ask yourself |
|------|-------------|
| 1. Understand | What is the **input**? What should the **output** be? |
| 2. Example | Can I solve a **small example** by hand? |
| 3. Plan | What steps did I follow by hand? |
| 4. Code | Can I turn those steps into code? |
| 5. Test | Does it work for **empty arrays**, **one item**, or **duplicates**? |

# 🟢 Level 1: Easy

## Problem 1: Sum and Average

**Task:** Find the total and the average marks of a student.

**Input:** `[78, 85, 92, 66, 74]`
**Output:** `Sum: 395, Average: 79`

💡 **Idea:** Add all the numbers, then divide the sum by how many numbers there are.

::js-playground
```js
const marks = [78, 85, 92, 66, 74];

// Method 1: Using a loop
let sum = 0;
for (const mark of marks) {
  sum += mark;
}

// Method 2: Using reduce (same result)
const sum2 = marks.reduce((total, mark) => total + mark, 0);

const average = sum / marks.length;

console.log(`Sum: ${sum}, Average: ${average}`);
console.log(`Sum with reduce: ${sum2}`);
```

## Problem 2: Largest and Smallest Number

**Task:** Find the highest and the lowest score in a cricket series.

**Input:** `[45, 110, 82, 23, 67]`
**Output:** `Max: 110, Min: 23`

💡 **Idea:** Start by assuming the **first** number is both the biggest and the smallest. Then check every number and update if you find a bigger or smaller one.

::js-playground
```js
const runs = [45, 110, 82, 23, 67];

// Method 1: Step by step (shows the logic)
let max = runs[0];
let min = runs[0];

for (const run of runs) {
  if (run > max) max = run;
  if (run < min) min = run;
}

console.log(`Max: ${max}, Min: ${min}`);

// Method 2: The quick way with Math and spread
console.log(`Max: ${Math.max(...runs)}, Min: ${Math.min(...runs)}`);
```

## Problem 3: Count Even and Odd Numbers

**Input:** `[1, 2, 3, 4, 5, 6, 7]`
**Output:** `Even: 3, Odd: 4`

💡 **Idea:** A number is **even** if dividing it by 2 leaves **no remainder** (`n % 2 === 0`).

::js-playground
```js
const nums = [1, 2, 3, 4, 5, 6, 7];

let even = 0;
let odd = 0;

for (const n of nums) {
  if (n % 2 === 0) {
    even++;
  } else {
    odd++;
  }
}

console.log(`Even: ${even}, Odd: ${odd}`);

// Short way with filter
console.log("Even numbers:", nums.filter((n) => n % 2 === 0));
```

## Problem 4: Reverse an Array (Without `reverse()`)

**Input:** `[1, 2, 3, 4, 5]`
**Output:** `[5, 4, 3, 2, 1]`

💡 **Idea:** Swap the **first** and **last** items, then move **inward** from both sides. It's like two people standing at the two ends of a line and walking towards each other, swapping places each step. This is called the **two-pointer** technique.

```
[1, 2, 3, 4, 5]
 ↑           ↑    swap 1 and 5 → [5, 2, 3, 4, 1]
    ↑     ↑       swap 2 and 4 → [5, 4, 3, 2, 1]
       ↑          they meet → stop ✅
```

::js-playground
```js
const nums = [1, 2, 3, 4, 5];

let left = 0;
let right = nums.length - 1;

while (left < right) {
  [nums[left], nums[right]] = [nums[right], nums[left]];   // swap
  left++;
  right--;
}

console.log(nums);   // [5, 4, 3, 2, 1]
```

## Problem 5: Check if an Item Exists

**Task:** Check if a city is on the delivery list.

**Input:** `["Delhi", "Pune", "Jaipur"]`, search: `"Pune"`
**Output:** `Pune is available ✅`

💡 **Idea:** Go through each item. If it matches, stop and say "found."

::js-playground
```js
const deliveryCities = ["Delhi", "Pune", "Jaipur"];
const search = "Pune";

// Method 1: Using a loop
let found = false;
for (const city of deliveryCities) {
  if (city === search) {
    found = true;
    break;   // no need to check further
  }
}
console.log(found ? `${search} is available ✅` : `${search} is not available ❌`);

// Method 2: Using includes()
console.log(deliveryCities.includes("Chennai"));   // false
```

# 🟡 Level 2: Medium

## Problem 6: Remove Duplicates

**Task:** Remove repeated drinks from an order list.

**Input:** `["Tea", "Coffee", "Tea", "Juice", "Coffee"]`
**Output:** `["Tea", "Coffee", "Juice"]`

💡 **Idea:** Keep an item only the **first time** you see it.

::js-playground
```js
const drinks = ["Tea", "Coffee", "Tea", "Juice", "Coffee"];

// Method 1: Using a loop
const unique1 = [];
for (const drink of drinks) {
  if (!unique1.includes(drink)) {
    unique1.push(drink);
  }
}
console.log(unique1);

// Method 2: Using filter + indexOf
const unique2 = drinks.filter((drink, i) => drinks.indexOf(drink) === i);
console.log(unique2);

// Method 3: Using Set (shortest!)
const unique3 = [...new Set(drinks)];
console.log(unique3);
```
::

> A **`Set`** is a special collection that stores only **unique** values. Converting an array to a Set automatically removes duplicates.

## Problem 7: Count How Often Each Item Appears

**Task:** Count the votes for each snack at a class party. 🍿

**Input:** `["Samosa", "Pizza", "Samosa", "Momos", "Pizza", "Samosa"]`
**Output:** `{ Samosa: 3, Pizza: 2, Momos: 1 }`

💡 **Idea:** Use an object like a **tally sheet**. Every time you see a snack, add 1 to its count.

::js-playground
```js
const votes = ["Samosa", "Pizza", "Samosa", "Momos", "Pizza", "Samosa"];

const count = {};

for (const snack of votes) {
  count[snack] = (count[snack] || 0) + 1;
}

console.log(count);   // { Samosa: 3, Pizza: 2, Momos: 1 }
```
::

**How `(count[snack] || 0) + 1` works:**
- First time we see "Samosa" → `count["Samosa"]` is `undefined` → `undefined || 0` gives `0` → `0 + 1 = 1`
- Next time → `count["Samosa"]` is `1` → `1 + 1 = 2`

## Problem 8: Find the Second Largest Number

**Input:** `[10, 45, 32, 45, 28]`
**Output:** `32`

💡 **Idea:** Keep track of the **top two** numbers while going through the list **once**. Be careful: `45` appears twice, but the second largest is still `32`.

::js-playground
```js
const nums = [10, 45, 32, 45, 28];

let first = -Infinity;
let second = -Infinity;

for (const n of nums) {
  if (n > first) {
    second = first;   // old first becomes second
    first = n;        // new first
  } else if (n > second && n !== first) {
    second = n;
  }
}

console.log(second);   // 32
```
::

**Another way (simpler, but slower for big arrays):**

::js-playground
```js
const nums = [10, 45, 32, 45, 28];

const unique = [...new Set(nums)];          // remove duplicates
unique.sort((a, b) => b - a);               // biggest first

console.log(unique[1]);   // 32
```

## Problem 9: Find the Missing Number

**Task:** Roll numbers from 1 to 6 should be present, but **one student is absent**. Find the missing roll number.

**Input:** `[1, 2, 4, 5, 6]`
**Output:** `3`

💡 **Idea:** The sum of numbers from 1 to n is `n × (n + 1) ÷ 2`. Find what the sum **should be**, subtract what it **actually is**, and the difference is the missing number! 🧠

::js-playground
```js
const rollNumbers = [1, 2, 4, 5, 6];

const n = rollNumbers.length + 1;              // should be 6 numbers
const expectedSum = (n * (n + 1)) / 2;         // 1+2+3+4+5+6 = 21
const actualSum = rollNumbers.reduce((a, b) => a + b, 0);   // 18

console.log(`Missing roll number: ${expectedSum - actualSum}`);   // 3
```

## Problem 10: Move All Zeros to the End

**Input:** `[0, 1, 0, 3, 12]`
**Output:** `[1, 3, 12, 0, 0]`

💡 **Idea:** Separate the non-zero numbers and the zeros, then put them back together. The order of the non-zero numbers must stay the same.

::js-playground
```js
const nums = [0, 1, 0, 3, 12];

// Method 1: Using filter
const nonZeros = nums.filter((n) => n !== 0);
const zeros = nums.filter((n) => n === 0);
console.log([...nonZeros, ...zeros]);   // [1, 3, 12, 0, 0]

// Method 2: In place, without a new array
const arr = [0, 1, 0, 3, 12];
let position = 0;

for (let i = 0; i < arr.length; i++) {
  if (arr[i] !== 0) {
    [arr[position], arr[i]] = [arr[i], arr[position]];
    position++;
  }
}
console.log(arr);   // [1, 3, 12, 0, 0]
```

## Problem 11: Find Common Items in Two Arrays

**Task:** Find the friends who are coming to **both** parties. 🎉

**Input:** `["Amit", "Neha", "Ravi", "Sara"]` and `["Ravi", "Kiran", "Amit"]`
**Output:** `["Amit", "Ravi"]`

💡 **Idea:** Keep only the items from the first list that are **also in** the second list.

::js-playground
```js
const party1 = ["Amit", "Neha", "Ravi", "Sara"];
const party2 = ["Ravi", "Kiran", "Amit"];

const both = party1.filter((friend) => party2.includes(friend));

console.log(both);   // ["Amit", "Ravi"]
```

## Problem 12: Split an Array into Groups (Chunks)

**Task:** Divide students into teams of 2 for a project.

**Input:** `["A", "B", "C", "D", "E"]`, team size: `2`
**Output:** `[["A", "B"], ["C", "D"], ["E"]]`

💡 **Idea:** Jump forward by the team size each time, and `slice()` out one group.

::js-playground
```js
function makeTeams(students, size) {
  const teams = [];

  for (let i = 0; i < students.length; i += size) {
    teams.push(students.slice(i, i + size));
  }

  return teams;
}

console.log(makeTeams(["A", "B", "C", "D", "E"], 2));
// [["A", "B"], ["C", "D"], ["E"]]
```
::

# 🔴 Level 3: Interview Favourites

## Problem 13: Two Sum ⭐

**Task:** Find the **positions** of two numbers that add up to a target.

**Input:** `nums = [2, 7, 11, 15]`, `target = 9`
**Output:** `[0, 1]` (because `2 + 7 = 9`)

This is one of the **most famous** coding interview questions!

### Approach 1: Check every pair (simple, but slow)

💡 **Idea:** Try every possible pair of numbers.

::js-playground
```js
function twoSumSlow(nums, target) {
  for (let i = 0; i < nums.length; i++) {
    for (let j = i + 1; j < nums.length; j++) {
      if (nums[i] + nums[j] === target) {
        return [i, j];
      }
    }
  }
  return [];
}

console.log(twoSumSlow([2, 7, 11, 15], 9));   // [0, 1]
```
::

This works, but for 1,000 numbers it checks about **500,000 pairs**! 🐢

### Approach 2: Remember what you've seen (fast)

💡 **Idea:** For each number, ask: *"Have I already seen the number I need to reach the target?"* Keep a **notebook** (an object) of numbers you've seen, and where you saw them.

```
target = 9
see 2 → need 7 → not seen yet → note down: { 2: 0 }
see 7 → need 2 → seen at index 0! ✅ → answer [0, 1]
```

::js-playground
```js
function twoSum(nums, target) {
  const seen = {};   // number → index

  for (let i = 0; i < nums.length; i++) {
    const needed = target - nums[i];

    if (needed in seen) {
      return [seen[needed], i];
    }

    seen[nums[i]] = i;
  }

  return [];
}

console.log(twoSum([2, 7, 11, 15], 9));   // [0, 1]
console.log(twoSum([3, 2, 4], 6));        // [1, 2]
```
::

This checks each number **only once**. 🚀

## Problem 14: Rotate an Array

**Task:** Rotate the array to the **right** by `k` steps.

**Input:** `[1, 2, 3, 4, 5]`, `k = 2`
**Output:** `[4, 5, 1, 2, 3]`

💡 **Idea:** Take the **last k items** and move them to the **front**. Like a **merry-go-round** 🎠: each step, the last seat comes around to the front.

::js-playground
```js
function rotate(arr, k) {
  k = k % arr.length;   // rotating 7 times on 5 items = rotating 2 times
  if (k === 0) return [...arr];

  const lastPart = arr.slice(-k);        // [4, 5]
  const firstPart = arr.slice(0, -k);    // [1, 2, 3]

  return [...lastPart, ...firstPart];
}

console.log(rotate([1, 2, 3, 4, 5], 2));   // [4, 5, 1, 2, 3]
console.log(rotate([1, 2, 3, 4, 5], 7));   // [4, 5, 1, 2, 3]
console.log(rotate([1, 2, 3, 4, 5], 5));   // [1, 2, 3, 4, 5]
```

## Problem 15: Merge Two Sorted Arrays

**Input:** `[1, 4, 7]` and `[2, 3, 8]`
**Output:** `[1, 2, 3, 4, 7, 8]`

💡 **Idea:** Imagine two queues, both sorted by height. Compare the **front person** in each queue, and send the **shorter one** forward first. Repeat until both queues are empty.

::js-playground
```js
function mergeSorted(a, b) {
  const result = [];
  let i = 0;
  let j = 0;

  while (i < a.length && j < b.length) {
    if (a[i] < b[j]) {
      result.push(a[i]);
      i++;
    } else {
      result.push(b[j]);
      j++;
    }
  }

  // add whatever is left in either array
  return [...result, ...a.slice(i), ...b.slice(j)];
}

console.log(mergeSorted([1, 4, 7], [2, 3, 8]));   // [1, 2, 3, 4, 7, 8]
```

## Problem 16: Maximum Profit from Stock Prices 📈

**Task:** You are given the price of a stock for each day. Buy on one day and sell on a **later** day. Find the **maximum profit**.

**Input:** `[7, 1, 5, 3, 6, 4]`
**Output:** `5` (buy at 1, sell at 6)

💡 **Idea:** Go day by day. Remember the **lowest price** seen so far. On each day, check: *"If I sell today, how much profit would I make?"*

::js-playground
```js
function maxProfit(prices) {
  let lowestPrice = prices[0];
  let bestProfit = 0;

  for (const price of prices) {
    if (price < lowestPrice) {
      lowestPrice = price;                  // found a cheaper day to buy
    } else if (price - lowestPrice > bestProfit) {
      bestProfit = price - lowestPrice;     // found a better day to sell
    }
  }

  return bestProfit;
}

console.log(maxProfit([7, 1, 5, 3, 6, 4]));   // 5
console.log(maxProfit([7, 6, 4, 3, 1]));      // 0 (prices only fall, so don't buy)
```

## Problem 17: Maximum Sum of a Continuous Part (Kadane's Algorithm)

**Task:** Find the largest sum of any **continuous** part of the array.

**Input:** `[-2, 1, -3, 4, -1, 2, 1, -5, 4]`
**Output:** `6` (from the part `[4, -1, 2, 1]`)

💡 **Idea:** Walk through the array, keeping a **running total**. If the running total becomes **negative**, it will only pull the next numbers down, so **start fresh** from the next number.

It's like a **road trip** 🚗: if you've lost more than you've gained so far, forget the past and restart the journey from here.

::js-playground
```js
function maxSubarraySum(nums) {
  let current = nums[0];
  let best = nums[0];

  for (let i = 1; i < nums.length; i++) {
    current = Math.max(nums[i], current + nums[i]);   // continue, or start fresh?
    best = Math.max(best, current);
  }

  return best;
}

console.log(maxSubarraySum([-2, 1, -3, 4, -1, 2, 1, -5, 4]));   // 6
console.log(maxSubarraySum([-3, -1, -2]));                      // -1
```

## Common Patterns You Just Learned

| Pattern | Used in | Idea |
|---------|---------|------|
| **Running total** | Sum, average, max profit | Keep updating one value while looping |
| **Track the best** | Max/min, second largest | Remember the best value seen so far |
| **Tally sheet (object)** | Count items, two sum | Store what you have seen in an object |
| **Two pointers** | Reverse, merge sorted | Move two positions towards each other or side by side |
| **Set** | Remove duplicates | A collection of unique values |
| **Maths trick** | Missing number | Use a formula instead of a loop |

## Tips for Solving Array Problems

- ✅ Always test with **edge cases**: an empty array `[]`, one item `[5]`, negative numbers, and duplicates.
- ✅ Write a **simple solution first**, even if it's slow. Make it faster later.
- ✅ Use **clear variable names** like `highest`, `total`, and `seen`, not `x` or `temp`.
- ✅ Use **`console.log()`** inside loops to see what is happening at each step.
- ✅ Practice **a little every day**. Consistency beats a long session once a week. 🚀

## Key Takeaways

- Solving problems is the **best way** to master arrays. **Try first**, then check the solution.
- Most array problems use a few **common patterns**: running totals, tracking the best value, tally objects, two pointers, and Sets.
- **`reduce()`** is great for totals and counts, while **`filter()`**, **`includes()`**, and **`Set`** make many problems short and simple.
- A slow solution that **works** is a great start. Then look for a faster idea, like in **Two Sum**.
- Break every problem into **small steps**, and solve them one at a time. 🧩
